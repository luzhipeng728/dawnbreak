# 浮空 / 倒地 / 受身蹲伏（刷图 + 决斗共用）

代码：`src/engine/combat.js` 的 `JUGGLE` 参数表、`react()`、`airGravity()`、`airRecover()`；`src/engine/entity.js` 的落地 / 弹地；`src/game/player.js` 的受身蹲伏；AI 在 `src/game/fighter_ai.js`。
测试：`node test/juggle.mjs`（量化：滞空、追加浮空递减、弹地、重怪、刷图连击上限、决斗浮空保护、受身蹲伏、AI 用蹲伏 / 压起身）。

## 1. 官方模型（调研结论）
- **重量**：同一个技能，目标越重挑得越低；领主起身更快。霸体目标不浮空（照常受伤）；破霸体后被挑起的霸体怪，空中再打也不会被托高。
- **浮空力按技能单独设定**（官方公告会直接改某个技能的“浮空力”）。
- **越连越沉**：同一轮连击里空中挨打越多，下落越快；追加浮空能延长，但高度递减。
- **倒地追击**：只有能打倒地的攻击才打得到；追击次数有限，之后强制起身。
- **决斗保护**：浮空保护（浮空中累计掉 20% HP 开始加速下落，之后每多 5% 再加重一级，血条下蓝条）、倒地保护（倒地后累计 20% → 强制站起 + 0.7 秒无敌）、平推保护（站立挨打 20% → 强制击倒、霸体）、硬直 / 时间保护（连招越长硬直越短）；保护约 3 秒没挨打清零；浮空 / 倒地 / 站立受到的伤害分别是 85% / 100% / 100%（我们没做 85%）。
- **受身蹲伏**：倒地时按跳跃键马上起身蹲伏，蹲着无敌；老数据：刷图冷却 5 秒、1 级无敌 3 秒、起身霸体 0.3 秒；决斗冷却 20 秒、1 级无敌 1.5 秒、起身霸体 0.1 秒；蹲着可以起身跑开；蹲太久对手会等你无敌结束再打（心理战）。

## 2. 我们的模型（`JUGGLE`）
| 参数 | 值 | 含义 |
|---|---|---|
| `grav` | 1150 | 浮空状态的重力（跳跃等仍是 `GRAV` 1500） |
| `apexV` / `apexFloat` | 80 / 0.75 | 最高点附近重力 ×0.75，顶点停一下方便追击 |
| `weightExp` / `bossRes` | 0.5 / 0.7 | 浮空力 ÷ 重量^0.5（高度 ∝ 1/重量）；领主再 ×0.7 |
| `relaunch` / `relaunchMin` | 0.87 / 0.4 | 同一轮连击第 n 次挑空（含空中 / 倒地再挑）× 0.87ⁿ |
| `airLift` / `airDecay` / `airMin` | 160 / 0.93 / 0.2 | 空中普通受击：力度 k = 0.93^空中受击数；上升中保留 96% 速度（`riseKeep`），下落中按 k 把速度拉回托力 |
| `gravStep` / `gravMax` | 0.03 / 0.9 | 每次空中受击重力 +3%，最多 +90% |
| `pveLateT` / `pveLate` / `pveLateLaunch` | 5 秒 / ×2 / ×0.3 | 刷图：同一轮浮空（含打击停顿）超过 5 秒 → 重力 ×2、挑空 ×0.3、不再接住 |
| `bounceImp` / `bounceK` | 330 / 0.32 | 落地速度 > 330 且这轮没弹过 → 弹一次；`spike` + `bounce: k` 强制弹（至少 260） |
| `otgMax` / `otgLift` | 4 / 110 | 怪物被倒地追击超过 4 次强制起身；追击把目标轻轻托起 |
| `pvpGrav` / `pvpLaunch` / `pvpRecover` | +60% / ×0.55 / 4 级 | 决斗浮空保护每级（20% 起每 5% 一级）；第 4 级（35%）**强制空中受身**：无敌、站着落地、不能追击 |
| `pvpAirT` / `pvpAirRamp` | 3 秒 / +80%/秒 | 决斗：同一轮浮空超过 3 秒重力继续加 |

技能写法（职业文件不用改，数值直接按新模型解释）：`launch` 挑空力（520 ≈ 普通怪 118 像素、滞空约 1 秒；300 ≈ 40 像素；720 ≈ 225 像素）、`airLift` 空中托力、`spike` 向下砸 + `bounce` 弹地倍率、`down` + `downLift` 击倒、`otgLift` 倒地追击托力、`downHit` 能打倒地。

提示：决斗里浮空保护每升一级目标闪一下蓝光（第 1 级飘“浮空保护”），血条下蓝条 = 浮空保护、黄条 = 倒地保护；强制受身飘“受身”。

## 3. 受身蹲伏 / 起身
| 规则 | 地下城 | 决斗场 |
|---|---|---|
| 输入 | 倒地后（落地瞬间也行，有输入缓冲）按 C | 同左 |
| 无敌 | 蹲伏全程；按住 C 最长 3 秒 | 最长 1.5 秒 |
| 移动 | 蹲着按方向慢慢挪（35% 走路速度），决定起身位置和朝向 | 同左 |
| 起身 | 松开 C 起身，霸体 0.3 秒 | 霸体 0.1 秒 |
| 冷却 / 消耗 | 5 秒 / 1 MP | 20 秒 / 1 MP |
| 被追击 / 抓取 | 无敌中打不到、抓不到 | 同左 |
| 普通起身 | 无敌 1.1 秒（怪物 0.55） | 0.7 秒；受身 0.6 秒 |

压起身：对手快要起身时贴上去出招可以打到“普通起身”后无敌结束的那一下；用受身蹲伏多蹲一会儿（等对方招出完）再起就能躲开。
显示：蹲伏中身上淡蓝光；决斗血条下面显示双方的“受身蹲伏 就绪 / N 秒 / 蹲伏中（无敌）”（联机两端都能看到）。
AI：倒地后按难度决定是否蹲伏，一半马上起、一半多蹲 0.5~1.3 秒；对手在身边出招就继续蹲；进攻方在对方快起身时贴身出招（压起身），对方在蹲伏就退开等。
