## 1. 官方模型（调研结论）
- **重量**：同一个技能，目标越重挑得越低；领主起身更快。霸体目标不浮空（照常受伤）；破霸体后被挑起的霸体怪，空中再打也不会被托高。
- **浮空力按技能单独设定**（官方公告会直接改某个技能的“浮空力”）。
- **越连越沉**：同一轮连击里空中挨打越多，下落越快；追加浮空能延长，但高度递减。
- **倒地追击**：只有能打倒地的攻击才打得到；追击次数有限，之后强制起身。
- **决斗保护**：浮空保护（浮空中累计掉 20% HP 开始加速下落，之后每多 5% 再加重一级，血条下蓝条）、倒地保护（倒地后累计 20% → 强制站起 + 0.7 秒无敌）、平推保护（站立挨打 20% → 强制击倒、霸体）、硬直 / 时间保护（连招越长硬直越短）；保护约 3 秒没挨打清零；浮空 / 倒地 / 站立受到的伤害分别是 85% / 100% / 100%（我们没做 85%）。
- **受身蹲伏**：倒地时按跳跃键马上起身蹲伏，蹲着无敌；老数据：刷图冷却 5 秒、1 级无敌 3 秒、起身霸体 0.3 秒；决斗冷却 20 秒、1 级无敌 1.5 秒、起身霸体 0.1 秒；蹲着可以起身跑开；蹲太久对手会等你无敌结束再打（心理战）。

- **刷图（PVE）**（2026-10 补充调研）：
  - 官方没有固定的浮空时限，连招多长只由保护决定（下面几篇资料都只讲按伤害触发的保护，没有任何“浮空 N 秒”的规则）。
  - **重力保护（중력 보정）**：空中挨打越多越重、滞空越短；地下城里也有，只是触发的伤害线定得很高。韩服 namu wiki 记载：目前地下城里只对**领主和 APC** 生效（适正等级 60 以上的地下城里**精英（네임드）**也有），普通怪 / 冠军没有；自己的角色在地下城空中挨打也会变重。
  - **保护线之前下落速度都一样**，过了保护线越来越快，再往后“挑空完全无效、直接摔在地上”（DFO Wiki PvP Mechanics；PK 的规则，刷图按同一套机制理解）。
  - **地面保护（바닥 보정）**：决斗和地下城都有。倒地挨打到一定程度强制站起（带短暂无敌）；**打得越多，追击托起得越低**，快起身时只在地上抽动（namu wiki）。
  - 落地保护只在真正落地后才算；被扫地打成小浮空时，要等小浮空落回地面才触发（52PK / 7k7k「PKC 定律」第五定律）。起身时浮空保护加的重量和落地保护一起清零（同上）。
  - 霸体怪被破霸体挑起后，空中再打不会被托高、直接落地（腾讯新闻 DNF 杂谈）；怪物完全落地后多数会快速起身 / 无敌，浮空连要靠有浮空力的技能和滞空技能穿插维持（18183 暗刃 PVE 空连）。
  - **不确定**：地下城里保护线的具体数值、普通怪到底有没有保护、地面保护按伤害还是按次数，官方都没有公开；我们按“浮空点数”定线（领主血量太高，按 HP% 永远到不了），数值见 §5，主人可以按手感调。

## 2. 我们的模型（`JUGGLE`）
| 参数 | 值 | 含义 |
|---|---|---|
| `grav` | 1150 | 浮空状态的重力（跳跃等仍是 `GRAV` 1500） |
| `apexV` / `apexFloat` | 80 / 0.75 | 最高点附近重力 ×0.75，顶点停一下方便追击 |
| `weightExp` / `bossRes` | 0.5 / 0.7 | 浮空力 ÷ 重量^0.5（高度 ∝ 1/重量）；领主再 ×0.7 |
| `relaunch` / `relaunchMin` | 0.87 / 0.4 | **决斗**：同一轮连击第 n 次挑空（含空中 / 倒地再挑）× 0.87ⁿ。刷图不用（见 §5） |
| `airLift` / `airDecay` / `airMin` | 160 / 0.93 / 0.2 | 空中普通受击托力 160；上升中保留 96% 速度（`riseKeep`），下落中按力度 k 把速度拉回托力。决斗 k = 0.93^空中受击数；刷图 k 由保护等级决定（自由段 1） |
| `gravStep` / `gravMax` | 0.03 / 0.9 | **决斗**：每次空中受击重力 +3%，最多 +90%。刷图重力只看保护等级 |
| `pveCeil` | 230 | 刷图高度上限（我们加的）：空中再挑最多挑到约 230 像素，空中受击在 170 像素以上托力逐渐减到 20%，不会被顶出屏幕 |
| `duelSumLateT` / `duelSumLate` | 5 秒 / ×0.3 | 只剩决斗里召唤物打决斗玩家沿用的旧时限。**刷图的 5 秒浮空时限（`pveLateT`）已取消** |
| `bounceImp` / `bounceK` | 330 / 0.32 | 落地速度 > 330 且这轮没弹过 → 弹一次；`spike` + `bounce: k` 强制弹（至少 260）；刷图一套最多强制弹 2 次 |
| `slamBounce` | 0.4 | 刷图扣地（`spike`）打站着的目标：砸倒并强制弹地的倍率（技能写了 `bounce` 用技能的） |
| `otgLift` | 110 | 追击把目标轻轻托起；刷图的追击额度、托起递减见 §5 |
| `pvpGrav` / `pvpLaunch` / `pvpRecover` | +60% / ×0.55 / 4 级 | 决斗浮空保护每级（20% 起每 5% 一级）；第 4 级（35%）**强制空中受身**：无敌、站着落地、不能追击 |
| `pvpAirT` / `pvpAirRamp` | 3 秒 / +80%/秒 | 决斗：同一轮浮空超过 3 秒重力继续加 |

技能写法（职业文件不用改，数值直接按新模型解释）：`launch` 挑空力（520 ≈ 普通怪 115 像素、滞空约 1.3 秒；300 ≈ 38 像素；720 ≈ 225 像素）、`airLift` 空中托力、`spike` 向下砸 + `bounce` 弹地倍率、`down` + `downLift` 击倒、`otgLift` 倒地追击托力、`downHit` 能打倒地、`jp` 这一下的浮空点数（刷图，不写按默认）、`force` 刷图里强制对倒地目标有受击反应（一般不用）。

提示：决斗里浮空保护每升一级目标闪一下蓝光（第 1 级飘“浮空保护”），血条下蓝条 = 浮空保护、黄条 = 倒地保护；强制受身飘“受身”。

## 3. 受身蹲伏 / 起身
| 规则 | 地下城 | 决斗场 |
|---|---|---|
| 输入 | 倒地后（落地瞬间也行，有输入缓冲）按 C | 同左 |
| 无敌 | 蹲伏全程；按住 C 最长 3 秒 | 最长 1.5 秒 |
| 移动 | 蹲着按方向慢慢挪（35% 走路速度），决定起身位置和朝向 | 同左 |
| 起身 | 松开 C 起身，霸体 0.3 秒 | 霸体 0.1 秒 |
| 冷却 / 消耗 | 5 秒 / 1 MP | 20 秒 / 1 MP |
| 被追击 / 抓取 | 无敌中打不到、抓不到 | 同左 |
| 普通起身 | 无敌 1.1 秒（怪物 0.55） | 0.7 秒；受身 0.6 秒 |

压起身：对手快要起身时贴上去出招可以打到“普通起身”后无敌结束的那一下；用受身蹲伏多蹲一会儿（等对方招出完）再起就能躲开。
显示：蹲伏中身上淡蓝光；决斗血条下面显示双方的“受身蹲伏 就绪 / N 秒 / 蹲伏中（无敌）”（联机两端都能看到）。
AI：倒地后按难度决定是否蹲伏，一半马上起、一半多蹲 0.5~1.3 秒；对手在身边出招就继续蹲；进攻方在对方快起身时贴身出招（压起身），对方在蹲伏就退开等。

## 5. 刷图浮空保护（2026-10，`src/engine/juggle_core.js`）
只管刷图（怪物、地下城里的玩家）；决斗仍是 `src/game/duel.js` 按 HP% 的那套（`docs/PVP.md`），没动。

**连招会话**（挂在目标的 `t.js` 上，纯 JSON）：`stand` 站着挨打 → `air` 被挑起 → `ground` 第一次落地后（倒地 / 打地小浮空 / 弹地）→ `air2` 倒地后被重新挑成正常浮空。站着挨打不累计点数；**目标起身动作结束就清零**（连同 `cmb` 连击统计），下一套从头算；能行动 1 秒没被打也清零（`COMBAT.protReset`）。

**一级 / 二级保护**（参数全在 `JUGGLE_PROT` 一张表里，怪物定义可写 `juggle: {...}` 覆盖）：
| 项 | 值 | 说明 |
|---|---|---|
| 点数 | 普通空中受击 1、`rep` 多段每段 0.5、挑空 3、击倒 2、砸地 1、追击每段 0.5；技能可写 `jp` | 被挑起之后才算；打击停顿 / 时间都不算 |
| 一级 / 二级线 | 普通怪 60 / 108，精英 40 / 72，领主 22 / 40；都 ÷ 重量^0.5 | 普通怪官方没有保护，这里给一个正常连招碰不到的高线，只防无限浮空 |
| 自由段（一级之前） | 再挑、接住、重力都**不衰减** | 官方：保护线之前下落速度都一样 |
| 一级 | 重力 ×1.6，越接近二级越重（到 ×2.5）；挑空 ×0.6、接住 ×0.6；目标闪一下蓝光 | |
| 二级 | 挑不起来（挑空按普通空中受击算）、接不住、重力 ×3，进二级那一下就开始往下掉；闪橙光 | 官方：“挑空完全无效、直接摔下来” |
| 时间 | **没有浮空时限** | 以前的 5 秒断崖（含打击停顿、一直不清零）已删除 |

**倒地规则**：
- 打地 / 扫地：倒地目标只有 `downHit` / `grabDown`（或 `force`）的攻击有受击反应。职业 / 怪物文件里上百处直接调 `applyHit` 的攻击（波动、场地、延迟出手）在 `applyHit` 里统一拦下：**照常扣血、不托起、不重置倒地时间、不吃追击额度**（`pveDownBlock`，伤害输出不变）。
- 追击额度**按招算**（一次出招 / 一个投射物 / 召唤物的一个动作算一招；直接调用、攻击者没在出招的每下各算一招）：4 招全部打得完，第 5 招打到 → 强制起身 + 无敌 0.7 秒。同一招最多托 10 段，之后只扣血。托起高度每多一段追击 −7%（最低 35%）。被托起后落回地面接着躺剩下的倒地时间（至少 0.25 秒），不再整段重置。组队时队员的命中包带上招的编号，主机按同样的规则算。
- 扣地：`spike` 打站着的目标直接砸倒并弹一下（`bounce` 不写按 0.4）；霸体只扣血；一套最多强制弹 2 次。
