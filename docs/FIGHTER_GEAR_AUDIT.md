# 格斗家装备审计（2026-09-30，B8 二期）

用户反馈：「格斗家好像气功的装备也没有，也不全，这一块缺的东西还不少」。目标：男格斗家（气功师 / 散打 / 街霸 / 柔道家）的装备和鬼剑士 / 神枪手 / 魔法师持平。
方法：页面里直接读物品库 / 掉落表 / 商店 / 深渊归属 / 对比窗口的口径，逐职业、逐转职对照（审计探针已经沉淀成测试：`node test/gear60.mjs jobs|content|power`，见 §5）。

### 1.2 防具 / 首饰 / 精通（共用，不缺）
- 史诗防具每种材质每段都有（布 2/4/6/5/9/11、轻 3/5/6/5/11/11、重 2/6/7/5/10/14），气功师布甲、散打 / 柔道轻甲、街霸重甲都有整套；精通加成按 `masteryOf`（布：智力 / 施放，轻：力量，重：力量 + 物防 + HP），转职里的 `J.armor` 生效 ✓。
- 首饰 / 辅助 / 魔法石、时之沙漏 / 流沙防具都不分职业 ✓。
- 异界套装（传说，每转职一套技能特化）：只有剑魂 / 狂战士 / 漫游 / 枪炮师 / 元素师 / 战斗法师 6 套，格斗家 4 个转职没有（另外 9 个转职也没有，见 §6）。

**属性**：两个转职是魔法职业，所以格斗家武器力智一起给（手套偏智力、臂铠 / 拳套偏力量、爪 / 东方棍对半），暴击 / 速度写成物理 + 魔法一对；元素只用属强（不做「属性攻击」——试过光属性攻击的 T1 拳套，全身配同属性装备后 Lv60 冲到 ×1.21）。

**系统修复**：G1 `mainStatOf(cls, job)` 按转职；商城增幅券默认属性改用它。G2 `gearMetrics` 对学了邪功修炼的街霸按力智 / 双暴击取高算。G3 随机史诗、随机武器、自选礼盒、流沙兑换都按 `wtypeJobOk` 过滤转职专用武器。G4 `lib_bestkit` / `power` 按转职的伤害类型、候选武器按转职过滤，power 多了「转职行」（伤害类型不同或有转职专用武器的转职）和职业之间的持平检查。

**拿在手里的外观**：格斗家的拳上武器由另一块按类型重画（品级 / 装扮靠换色），所以具名史诗不另画武器图，而是在物品上登记配色 `pal = { main, trim, glow }`（89 件，同类型同品级不撞色）；渲染层接上之前按 `<类型>_r4`（领主神器 `_r3`）显示。

## 6. 遗留
- 异界套装（传说，每转职一套技能特化）：格斗家 4 个转职没有；三职业也只有 6 个转职有，要做就一次补齐 13 个转职（每套 3 个图标）。
- 机械师（神枪手里的魔法转职）按魔法口径量出来 Lv40 ×0.86、Lv60 ×1.15（超 ±10%），是神枪手块按物理口径调的，power 里标成「已知」只提示不算失败。
- 具名史诗的拿在手里配色要等拳上武器按类型重画的那一块接 `ITEMS[key].pal`；接之前显示 `<类型>_r4` / `_r3`。
- 格斗家武器的官方特效只做了能用现有 proc 表达的（技能等级 +3 这类「念兽：龙虎啸 +3」没做）。
