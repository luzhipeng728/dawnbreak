# 转职外观（JOB_VISUALS）

转职后一眼看出是谁：常驻外观（鬼手 / 红眼 / 小鬼神…）+ 状态特效（BUFF / 阵 / 无敌）。全部是**运行时覆盖层**，叠在人物帧上面，所以任何时装、混搭都能用；城镇、地下城、选角、个人信息、决斗、其他玩家、组队影子、AI 对手都一样。

## 1. 官方依据与规格（阶段 A：鬼泣、狂战士）

| 转职 | 官方特征（国服 / namu） | 我们的做法 |
|---|---|---|
| 鬼泣 | 解开封印的左臂「鬼手」冒紫色鬼火，鬼神随身 | 副手（F.oh）上 2 条紫色鬼火舌 + 往上飘的光点；后背肩膀上方一只小鬼神（fx/jv_wisp）慢慢浮动 |
| 鬼泣 · 残影之凯贾（俗称鬼影步） | 「前冲的一定时间内进入无敌状态（1 秒）」；凯贾附身，身后有鬼影 | 身后跟着自己的紫色剪影（移动时拖远）；移动时 0.25 秒残影；**无敌时本体半透明（alpha ≈ 0.45）+ 鬼火微光**。机制：凯贾时开始跑动 → 1 秒无敌（每 3 秒一次，`sword_soul.js`） |
| 鬼泣 · 阵（萨亚 / 普戾蒙 / 罗刹） | 鬼神在场 | 阵在场时身边 2~4 只鬼火绕身体转（转到身后的那一半画在人物后面）——「鬼影重重」 |
| 狂战士（红眼） | 红眼、血红的鬼手 | 眼睛红光，移动时往后拖一道红光；副手血气火舌 + 往下滴血 |
| 狂战士 · 狂暴之力（血之狂暴） | 开启后全身血气燃烧，双刀流 | 身后一团血雾 + 红色外轮廓 + 沿身体两侧和头顶往上窜的血焰，身前再补几条小火舌；武器（含二刀流的副手刀）外圈染红光 |
| 狂战士 · 暴走 | 更强的血气 | 同上，强度 2：火更大、更多 |
| 狂战士 · 出血命中 | 出血 | 命中时溅血花（`jobFxBlood`，同一目标 0.15 秒一次） |
| 阿修罗 | 眼罩 | X 形眼罩（原来只有自己看得到，现在 look.acc 带着，其他玩家也看得到） |

### 阶段 C（格斗家男 4 个转职，B2，2026-09-30）

## 2. 代码结构

| 文件 | 内容 |
|---|---|
| `src/content/avatar/job_looks.js` | `JOB_LOOKS[转职] = { 数据 }`（字段说明见文件头）+ `jobLookAcc`（转职配件并进 look.acc） |
| `src/models/job_fx.js` | 渲染器：`jlUnder`（身后 / 半透明）、`jlOver`（身前）、`jlWeapon`（武器染色）；组件表 `JL_COMP`（ring / trail / ghost / aura / prop / pet / spirit / burn / orbit / wisps / motes / arcs / arm / eyes）、`jobFxBlood` |
| `src/models/avatar.js` | 外观层 `under` 开头调 `jlUnder`，`over` 结尾调 `jlOver`，`weapon` 在武器图之前调 `jlWeapon` |
| `src/content/avatar/looks.js` | `lookFromEquip(cls, eq, prefer, job)` 写 `look.job`（自己 = game.job；选角 = 存档里那个角色的 job） |
| `art/tools/avatar_hands.py` | 每帧副手锚点 `F.oh`（手套颜色找色块，去掉武器握点 / 靴子 / 腰带 / 头）；新动作帧切好后重跑 |
| `art/tools/jobvis_art.py` | 特效素材条（`fx/jv_flame` 4 格火舌、`fx/jv_wisp` 3 格鬼火精灵）：`gen` 生图 → `prep` 切条 |

- **转职从哪来**：`look.job`（自己 / 联机发来的 look）> 实体的 `kit.job`（AI、组队影子）。城镇里其他玩家没有实体 → 只画常驻外观，不画状态。
- **状态**：每帧 `S.on(e)` 返回强度（0 = 没开），读 `e.buffs` / 召唤物 / `e.invul`。
- **半透明**：`jlUnder` 在画本体之前把 `globalAlpha` 乘上去，`SpriteModel.draw` 的 save/restore 自动还原；超级霸体的离屏合成也照样生效。
- **性能**：不用 filter / shadowBlur，混合只用 source-over / lighter；剪影按（帧图, 颜色）缓存（LRU 160 张），火舌 / 鬼火是 fxTint 缓存的素材条。实测城镇 8 人（转职外观 + +13~+16 + 天空套）60 fps，地下城 4 个开状态的鬼剑士打怪 60 fps。

## 3. 新增一个转职（配方）

1. `JOB_LOOKS` 加一条：选颜色，挑组件（常驻：`orbit / prop / pet / ring / motes / aura / arm / eyes / spirit / wtint / acc`；`states` 里还可以用 `ghost / trail / fade / wisps / burn / arcs`），每个状态写 `name`、`on(e)`、`demo(e)`（测试和总览图靠它打开）。素材先找 `art/final/fx`、精灵帧（小伙伴）、武器图（背上的道具）。
2. 组件不够用 → 写 `draw(c, L, F, f, back, e)` 钩子（坐标 = 帧像素，原点脚底，人物朝右，`back` 区分身前身后）；能复用就把它提成新组件放进 `job_fx.js`。
3. 要新素材（背后的大件、专属火焰）→ `jobvis_art.py` 的 `FX` 加一行，`gen` → `prep`，`job_fx.js` 的 `JL_STRIP` 登记格数、`FX_BASE_HUE` 登记本色。
4. 其他职业（gun / mage）第一次用 `arm` / `eyes`：先跑 `avatar_hands.py <职业> --sheet 预览.jpg`（`GLOVE` 里加手套颜色）、在 `JL_EYE` 里加眼睛偏移。
5. `node test/jobvisuals.mjs shots` 出总览图（每个转职一排：城镇站立 / 走路 / 状态 / 混搭时装 + 状态跑动 / 地下城状态，原始 1 倍大小）；测试自动覆盖新条目（look.job / 配件 / 每个状态开关）。

## 4. 强化光效（面子系统，game/vanity.js）

光效分两次画：武器图**之前**画外层第二圈光晕、大光晕、紧贴刀身的实色描边（rim）、爆闪的光、电弧（刀身挡在前面，光从四周透出来）；武器图**之后**只画刀身外沿的火花、绕着武器转的光点（椭圆轨道把整把武器包在里面）和尖端星芒。
阶梯（`GLOW_ENH` / `GLOW_AMP` 一行一级）：+10 起刀身描边，+12 光晕约为旧版 2 倍，+13 变红 + 待机爆闪，+14 环绕光点，+15 变紫 + 双层光晕 + 脚下光环，+16 三色同时轮换 + 电弧 + 光点加倍。对比图：`node test/jobvisuals.mjs glow` → `test/shots/jobvisuals/glow.jpg`。

## 5. 头部：发色 + 头饰（转职后至少头不一样）

每个转职 = 发色（`JOB_LOOKS[转职].hair`）+ 一件头饰（`acc`，AVATAR_ACC 按每帧头部锚点叠加，和时装配件同一套机制）。官方依据：namu / 灰机 wiki 的转职立绘与选角图（没把握的按转职主题定，和用户给的方向一致）。

| 转职 | 官方头部特征 | 我们的做法 |
|---|---|---|
| 剑魂 | 棕发，额前系头带 | 栗棕发 + 藏青头带（额前银片、脑后两条长飘带） |
| 鬼泣 | 灰白发，鬼神附身 / 驱鬼符咒 | 灰紫发 + 太阳穴挂一张紫色鬼纹黄符 |
| 狂战士 | 红眼，乱发，绷带 | 暗红发 + 黑色破布头带（红边、滴血）+ 原有红眼光（第一版白色带血绷带在红发上像没染到的浅色斑块，换成深色） |
| 阿修罗 | 蒙眼（失明），白发 | 保持银白发 + 原有 X 形眼罩（压掉时装眼镜） |
| 剑影 | 黑发，幻鬼相伴 | 蓝黑发 + 黑色半面罩（遮口鼻） |
| 漫游枪手 | 牛仔帽 + 蔷薇（沾血蔷薇） | 黑色牛仔帽（暗红帽带 + 血色蔷薇），盖住默认报童帽；原来头上单独的蔷薇并进了帽子 |
| 枪炮师 | 重火力，护目镜 | 黄铜框橙色镜片大护目镜，推在帽子 / 额头上 |
| 机械师 | 机械工，工作帽 | 黄灰工作帽（齿轮徽章），盖住报童帽 |
| 弹药专家 | 头巾 / 军帽 | 红色战斗头巾（子弹挂坠，脑后打结） |
| 协战师 | 战术耳机 / 目镜 | 白蓝战术耳机（青色光环 + 麦克风） |
| 元素师 | 银蓝系发色，宝石头饰 | 银蓝发 + 银头环（冰蓝大水晶 + 红黄紫小宝石），戴在帽檐下的额头上 |
| 战斗法师 | 橙红发，武斗风 | 橙发 + 红色武斗头带（金片、长飘带） |
| 召唤师 | 绿发，契约兽 | 薄荷绿发 + 耳边一只卷曲的紫色契约兽角 |
| 魔道学者 | 学者眼镜，炼金 / 药水 | 焦糖棕发 + 金框大圆眼镜（带细链；深色头发和紫色巫师帽混在一起看不出，改用暖棕） |
| 小魔女 | 粉红发，哥特蝴蝶结 + 蔷薇 | 玫粉发 + 黑红哥特蝴蝶结（结心一朵红蔷薇） |
| 气功师 | 青绿道袍，念珠 | 栗棕发（不染）+ 念珠挂在脖子上（`job_nenmaster_beads`，和时装不冲突，一直画） |
| 散打 | 红头带（长飘带） | 红头带（`job_striker_band`，戴时装帽子时不画） |
| 街霸 | 街头混混，锁链 | 鼻梁创可贴（`job_brawler_plaster`，脸部配件，脸被挡住的帧不画） |
| 柔道家 | 柔道服 | 白头带（短结，`job_grappler_band`，戴时装帽子时不画） |

- **发色**（`models/job_fx.js` 的 `jlHair`，外观层 `over` 第一步调用 = 紧贴在帧图上、身前武器和头饰之前）：帧图没有单独的头发层，按颜色 + 头部锚点找头发像素（`JL_HAIR_PICK`），换成目标发色（保留明暗）盖回去；每（帧图, 颜色）算一次，缓存裁好的小画布（LRU 200），每人每帧多 1 次 drawImage。
  - 鬼剑士：银白短发（低饱和、够亮，只在头心附近找，避开眼睛和肤色）；魔法师：淡紫长发（按亮度和深紫的巫师帽 / 法袍分开，整条长发都染）。
  - **神枪手不染发**：棕发、默认报童帽、皮夹克是同一种棕，按颜色分不开（试过会把帽子和衣服一起染）→ 神枪手 5 个转职全部靠头饰区分（4 件盖住 / 压在报童帽上的帽子类 + 协战师的耳机）。
  - 时装帧缺头部锚点时借原装同名帧的（按脚底锚点对齐）。转职立绘（`art/final/job`）还是原来的发色，没有重画。
- **头饰位置**：`pos[职业]` = 默认造型的头（神枪手 / 魔法师戴着报童帽 / 巫师帽，头心在帽子上），`pos[职业@]` = 时装的头（没帽子）。魔法师的巫师帽画死在帧里，所以魔法师的头饰都选不跟巫师帽打架的（帽檐下的头环 / 头带、耳边的角、眼镜、脑后的蝴蝶结）。
- **和时装共存**（`AVATAR_ACC.job_*.clash` + `jobLookAcc`，时装优先）：戴着时装帽子 → 帽子类头饰不画（剑魂 / 狂战士 / 战斗法师的头带、牛仔帽、护目镜、工作帽、头巾、契约兽角）；戴着时装发饰 → 小魔女的蝴蝶结不画；戴着时装眼镜 → 魔道学者的眼镜不画；不挡帽子的一直画（鬼泣的符、剑影的面罩、协战师的耳机、元素师的头环）；阿修罗的眼罩照旧压掉时装眼镜。
- 格斗家（男）：默认造型不戴帽子，`pos.fighter` = `pos['fighter@']`（时装帧的头部锚点从原装平移过来，头的位置一样）；眼睛约在头心 [23, 22]（鬼剑士 [17, 22]），时装眼镜比鬼剑士往前 6。总览：`node test/fighter_looks.mjs shots` → `test/shots/fighter_looks/heads.jpg`。
- 出图：`python3 art/tools/job_head_art.py gen <id,...> -j 3` → `prep` → `node build.mjs`；看效果：`node test/jobvisuals.mjs heads`（3 个基础职业 + 15 个转职：站立 / 跑动 / 攻击 / 学院全套 / 炎龙跑动 / 头部特写 → `test/shots/jobvisuals/heads.jpg`；`HEADS=blade,ranger` 只出这几排）。
