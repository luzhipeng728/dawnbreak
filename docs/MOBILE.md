# 手机操作（触屏）

手机 / 平板自动启用虚拟按键（电脑上加 `?touch` 预览）。代码在 `src/engine/touch.js`，样式在 `src/shell_top.html` 的 `#touch` 段，左上角状态条在 `src/ui/hud.js` 的 `drawTouchPanel`，设置在 `src/ui/settings.js` 的「手机按钮」页。

## 1. 官方手游怎么做（2026-09-28 调研）

参考了两款官方手游：国服《地下城与勇士：起源》（2024）和韩服《던전앤파이터 모바일》（2022）。标“没查到”的是资料里找不到的，不代表官方没有。

| 项目 | 官方做法 | 来源 |
|---|---|---|
| 摇杆 | 在左边，有固定 / 移动 / 悬浮三种；可以调大小、灵敏度、位置和方向数（最多 32 向）。“推到底就跑”和“双击跑”没查到；冲刺（疾闪）用双击后跳键或拖后跳键 | [1][2] |
| 攻击、跳跃、后跳 | 预设有 标准型 / 扇形排列 / 按键排列 / 基础型 / 自由配置，前几种主要是跳跃和后跳的位置不同。后跳是单独一个键（双击后跳 = 疾闪，可以改成拖后跳键） | [2][4] |
| 技能怎么排 | 扇形排列就是技能围着攻击键摆一圈，同一屏大约 10 个技能格。另外有「滑屏键」（按住往 4 个方向滑，放 4 个技能）和「一键连招」（4 套，每套最多 5 个技能，冷却中的会自动跳过）。**没有翻页** | [2][3][4] |
| 觉醒 | 放在单独的两个觉醒栏里，离拇指远一点；觉醒技能的图标是红黄配色 | [5][6] |
| 指令 / 蓄力 / 按住 | 手游不用搓指令，点技能就直接放；滑屏键可以配“智能施法”（滑动瞄准）。蓄力类和按住类技能在触屏上怎么操作：没查到 | [1][2] |
| 冷却 / MP 不足 | 按钮上怎么显示：没查到 | — |
| 设置 | 摇杆的大小和位置；技能栏的预设 + 自由配置（在限定区域里拖到任意位置，改完要点保存）；“调整游戏界面位置”滑块，把按钮整体往屏幕边上拉。透明度滑块：没查到 | [1][2] |
| 受身（快速起身） | 韩服：倒地时按后跳键立刻起身（冷却单独算）。国服：没查到 | [4] |
| 其他 | 按住普攻会自动追怪、捡东西；药水在血量 / 蓝量低于设定值时自动喝；国服主菜单在右下角 | [4][7] |

## 2. 我们的布局（照官方的“扇形排列”做）

- **左边：摇杆**。默认是浮动的：按左半屏的哪里，摇杆就出现在哪里，手指拖远了底座会跟着走；设置里可以改成固定。平时左下角显示一个淡淡的摇杆，告诉玩家摇杆在这儿。轻推是走，推到底是跑，快速拨两下也能跑（官方没查到这两种跑法，是按 PC 版手感补上的）。
- **右下：攻击键**（最大的那个），按住就一直普攻（引擎本来就支持按住 X 连打）。
- **跳跃**在攻击键左下。倒地时点一下就是受身；按住往下滑就是后跳（手指按下后 90ms 内往下滑）。**后跳**另外有一个单独的键，在攻击键正上方。
- **技能**：10 个技能扇形排在攻击键外面两圈（里圈 3 个、外圈 7 个），对应技能栏 s0..s9。点一下直接放，不用搓指令；按住就是蓄力 / 持续（技能读的是“按键还按着没有”，所以按住手机按钮和按住键盘键是一样的）。
- **滑屏键**（虚线圈，在扇形左上方）：按住往 上 / 右 / 下 / 左 滑，对应 s10..s13；手一滑到方向就放技能，松手才算松键（所以蓄力类放在这里也能用）；只点一下就放上次滑过的那个方向。10 个技能加滑屏键里的 4 个 = 技能栏的 14 格全都能用到。官方没有翻页，所以我们也不做翻页。
- **觉醒键**（金色边框，最右上方，最多 2 个）：自动找技能栏里的觉醒技能，按等阶高的排前面，点了就放那一格的技能。技能栏里没有觉醒技能时不显示。
- **左上一列**：菜单 / 物品 / 技能 / 任务 / HP 药水 / MP 药水。在城镇里技能键、后跳键、滑屏键、觉醒键都会隐藏，只留下摇杆、攻击和跳跃。
- **状态**：手机上不画底下的技能栏和消耗品栏，改成左上角的 等级 + HP / MP / 经验 条 + BUFF 图标。
- **按钮上的显示**：技能图标；冷却时有一圈转圈的暗色 + 剩余秒数；MP 不够时蒙一层蓝；装填类显示 ×N；可以再按的（召唤物在场）亮绿边；还没学会的变灰。这些**每 0.1 秒才刷新一次，而且只在值变了的时候才写 DOM**，不会每帧都改页面。
- **尺寸和安全区**：尺寸单位 U = 屏幕高度的 1%（最多 4.6px，平板上按钮不会太大）。位置都是用 JS 按像素算出来的，并且加上刘海和底部横条的安全区（读的是 `env(safe-area-inset-*)`）。
- **竖屏**：显示“请把手机横过来玩”的动画，游戏暂停；安卓上还有一个「全屏横屏」按钮（全屏后锁成横屏）。
- **窗口**：打开任何窗口时虚拟按键都会隐藏，已经按着的键全部松开。窗口可以用手指拖标题栏移动，点 ✕ 关闭。技能窗口的列表以前在手机上滑不动：技能图标设了 `touch-action:none`，Chrome 会把整个窗口的触摸滑动都挡掉。现在触屏模式下改成了 `pan-y`，上下滑可以滚动，左右拖图标还能拖进技能栏，也可以先点技能再点格子。
- **设置 → 手机按钮**：按钮大小、不透明度、左右互换、固定摇杆，还有「拖动调整按钮位置」（编辑模式：每个按钮和摇杆都能拖，改的是相对默认位置的偏移，存在 `uiPref('touchPos')` 里）和「恢复默认布局」。

- **状态键**（右上角一列）：没放进技能栏的 Buff / 受击技能，最多 5 个；真正的 Buff（`S.buff` / `S.whenHit`）排前面，其余“方向 + 空格”的攻击技能（分身、瞬步、念气罩……）排后面，各自按学习等级。一列放 4 个，第 5 个（格斗家气功师有 5 个 Buff）在最上面一格的里侧。
- **男格斗家的指令在触屏上的按法**（2026-09-30，B9）：键盘上的指令技能都能放进技能格，点一下就放（按住↑+Z 的前踢、按住↓+Z 的下段踢、按住→+Z 的膝击、↓↓+C 的蹲伏……）；空中 C（空绞锤、裂石破天）= 跳起后再点跳跃键；鹰踏（空中 Z）= 跳起后点技能键，弹起后再点一次是第二踩；蹲着点攻击键 = 肩撞、点跳跃键 = 起身；跑攻中 X（疾风追击）= 摇杆推到底跑 + 点攻击键肩撞，再点攻击键追加；抛投 / 浮空凌云踢的 ↑ / ↓ 用摇杆；蓄念炮 / 野蛮冲撞按住技能键蓄力；街霸投掷物的装填数显示在按钮角标（×N）；气功师的风雷能量条在左上角 BUFF 行下面（原来压住 BUFF 倒计时，改了 y）。

跟官方不一样、以后可以考虑补的：一键连招、智能施法（滑动瞄准）、自动喝药、多套布局预设。

## 3. 测试

`node test/mobile.mjs [shots]`（约 30 秒）：用 iPhone 13 横屏模拟（isMobile + hasTouch，不加 `?touch`），通过 CDP `Input.dispatchTouchEvent` 发真的触摸事件（多根手指、按住、滑动）。覆盖这些：走 / 跑 / 双拨跑、按住连续普攻、14 格技能（扇形 10 个 + 滑屏键 4 个方向）、滑屏键点一下、蓄力（点一下 vs 按住的蓄力比例）、冷却 / MP 不足显示、后跳键、跳跃下滑后跳、点跳跃、倒地受身、觉醒键、物品栏开关和拖动窗口、技能列表触摸滚动、设置里的大小 / 编辑模式、竖屏暂停、两根手指（摇杆 + 攻击）清完一个房间，还有 CPU 降速 ×4 时的帧率。加 `shots` 会多出一张总览图 `test/shots/mobile/sheet.jpg`。

`node test/mobile_fighter.mjs [shots]`（约 30 秒，网址带 `?fighter=1`）：4 个转职的按键都在屏幕里、互不重叠、扇形 / 滑屏 / 觉醒键都有图标、状态键列出本转职的 Buff；空中 C、蹲伏（攻击 = 肩撞 / 跳跃 = 起身）、前踢、鹰踏、跑攻中 X、街霸装填角标、气功师风雷能量条不压住 BUFF 行。注意 CDP `Input.dispatchTouchEvent` 的 `touchEnd` 松开的是**列出来的**手指（列剩下的手指会把摇杆松掉），这个测试的 `up()` 按这个写。
