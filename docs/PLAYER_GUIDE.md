# 破晓地下城 · 游玩指南

一个单机网页版的横版格斗刷图游戏，玩法和键位参照经典的《地下城与勇士》（DNF），Q 版画风。
不用登录，打开网页就能玩，存档保存在浏览器里。电脑用键盘，手机横屏用触屏按键。

---

## 一、上手五分钟

1. 标题画面点 **进入游戏** → **创建角色**：选职业（鬼剑士 / 神枪手 / 魔法师），起个名字。
2. 在 **赛丽亚的房间** 醒来。走到赛丽亚身边按 **X** 对话，接下第一个主线任务。
3. 往右走出房间，到 **艾尔文防线** 的集市，找铁匠 **林纳斯**（头顶有 **?** / **!** 的就是有任务的 NPC）。
4. 从集市往右走出城，来到 **洛兰**。走到地下城的门口，选难度，点 **进入地下城**。
5. 打通领主房后翻一张卡牌（免费），点 **返回城镇**，你会站在刚才的门口。
6. 回城找林纳斯交任务，接下一个任务。之后跟着 **左上角的路线指引** 和 **右侧的任务追踪** 走就行。

> 不知道下一步去哪：看左上角的指引条，点 **自动前往**，角色会自己走过去（按任意方向键取消）。
> 也可以按 **L** 打开任务日志，按 **N** 打开世界地图。

## 二、操作

### 键盘（默认键位，可在 **O → 按键设置** 里改）

| 按键 | 作用 |
|---|---|
| ← → ↑ ↓ | 移动（↑↓ 是往屏幕里 / 外走）；快速双击 ← / → 奔跑 |
| **X** | 普通攻击（连按出连段）；奔跑中按 = 冲刺攻击；站在物品上按 = 拾取；城镇里在 NPC 旁边按 = 对话 |
| **C** | 跳跃（空中按 X = 跳跃攻击） |
| **↓ + C** | 后跳：往后跳开，起跳瞬间无敌。普攻中可以直接后跳；技能中、挨打时后跳脱身要先学通用技能「后跳-强化」（Lv.10，有冷却） |
| 倒地时按住 **C** | 受身蹲伏：落地后蹲着无敌（地下城最多 3 秒，决斗场 1.5 秒），蹲着可以慢慢挪，松开起身并短暂霸体；冷却 5 秒（决斗场 20 秒）。对手在身边压起身时，蹲着等他出完招再起 |
| **Z** | 指令键：方向 + Z 放技能（例如 ↓→ + Z） |
| **Space** | 指令键 2：方向 + Space 放另一类技能（多为 Buff，例如神枪手 ↓→ + Space 银弹）。Z 和 Space 是两个不同的键，互不代替 |
| **A S D F G H 左Shift** / **Q W E R T Y V** | 两排技能栏，共 14 格 |
| **1 ~ 6** | 消耗品栏（药剂） |
| **I** 物品 · **M** 个人信息 · **K** 技能 · **L** 任务 · **N** 地图 · **O** 设置 · **P** 决斗场 | 窗口 |
| **Esc** | 关闭最上面的窗口；没有窗口时打开系统菜单 |
| Tab | 切换界面完整 / 简洁 |
| Ctrl | 显示地上掉落物的名字 |
| F12 | 截图 |

- 屏幕右下角也有一排菜单按钮（物品、个人、技能……），用鼠标点也行。
- 城镇里也可以直接用鼠标点 NPC 对话。
- 窗口可以按标题栏拖动。I、M、K 同时打开时会自动并排摆好（技能窗口会变成紧凑版，鼠标停在技能图标上看说明）。

### 手机（横屏）

- **左半屏**：按住任意位置出现摇杆，推到底 = 奔跑。
- **右侧**：大按钮 **X** 攻击，旁边是跳跃、指令（Z）、指令 2（Space）、后跳（等于 ↓ + C），以及 7 个技能按钮（可以翻页切换两排）。倒地时按住跳跃键 = 受身蹲伏。
- **左上**：药剂、技能翻页、物品栏、技能、任务、菜单。
- 城镇里点 NPC 就能对话；打开任何窗口时虚拟按键会暂时隐藏，用窗口右上角的 **✕** 关闭。
- **设置 → 手机按钮** 可以调按钮大小、透明度、左右互换。
- 竖屏时会提示把手机横过来。

## 三、战斗小知识

- **连段**：连按 X 打出普攻连段；攻击技能可以取消普攻（Buff 技能不行）。技能接技能只有官方规定的几种（例如神枪手奔跑中按 X 滑铲，滑铲中再按 X 接上旋踢），其他时候要等技能放完。
- **神枪手普攻**：先拔枪再开火，一轮打完自动收枪；按住 X 会自动接下一轮。官方没有 ↑X 上射，子弹都是平飞的。
- **指令释放**：方向 + Z（或 Space）放技能，和按技能栏效果一样（官方现版本没有指令减 MP / 冷却的加成）。在技能窗口右键技能图标，可以 **锁定指令**（只能用技能栏放）。
- **COUNTER**：在敌人出招时打中它，伤害 ×1.25。**BACK ATTACK**：从背后打。把敌人挑到空中连击可以提高评价。
- **预警**：地上出现 **黄色法阵 / 红色六芒星 / 红色冲撞路线** 就是马上要落下的攻击，走出范围或后跳躲开。
  领主头顶出现红色 **!** 是霸体重招，赶紧走开或后跳。地震、陨石、爆炸这类地面攻击可以跳起来躲。
- **远程小怪优先**：扔石头 / 火瓶的哥布林、普拉格站在远处，不先解决会一直被砸。
- **回血**：4 秒没挨打会慢慢回血；也可以喝药（1、2 键）。
- **倒地**：倒下时按 X 用复活币原地复活（每天送 1 枚，商店也能买）。复活币用完会回城并“虚弱” 10 分钟（大圣堂的歌兰蒂斯、药剂商人索西雅可以花钱解除）。
- **评价**：右下角的实时评价（操作 / 技巧 / 被击）。被击越多评价越低，评价越高通关经验加成越多。
- **疲劳值**：每进一个新房间消耗 1 点，每天恢复。

- **商店**：点物品勾选（可多选），Shift + 点击输入数量，右键直接买 1 个；“出售”页可以一键全选普通物品卖掉，卖错了在“回购”页买回来。
- **强化**：+1~+3 必定成功，+4 起失败会降级，武器 +12、防具 / 首饰 +10 以上失败会破碎（可用强化保护券）。需要金币和无色小晶块。
- **武器光效**：武器强化越高越亮，别人一眼能看出是 +几：+5~+8 淡黄微光，+9 冰蓝，+10 白蓝（开始冒火花），+11 湛蓝（出招有拖尾），+12 深蓝，+13 烈红（每隔几秒爆闪一下），+14 绯红，+15 紫耀（脚下光环），+16 七彩（再加电弧）。增幅的武器是血红 + 紫色碎片的另一套光效。+10 起城镇名牌旁边会显示 “+13” 这样的徽章。
- **穿装备**：在物品栏（I）右键装备，或拖到个人信息（M）的装备格子上。装备图标上的角标会提示比身上的好还是差。
- **仓库**：赛丽亚处。分“角色仓库”和所有角色共用的“账号金库”（可以存物品和金币，用来给小号转东西）。
- **世界地图（N）**：点地点查看 NPC 和地下城；在城镇里可以直接传送到去过的城镇。

## 五、玩法路线

| 等级 | 地区 | 地下城 |
|---|---|---|
| 1~3 | 洛兰（艾尔文防线往右） | 洛兰、洛兰深处 |
| 3~7 | 格兰之森 · 幽暗密林 | 幽暗密林、幽暗密林深处、*冰霜幽暗密林（隐藏）* |
| 6~11 | 格兰之森 · 雷鸣废墟 | 雷鸣废墟、猛毒雷鸣废墟、*暗黑雷鸣废墟（隐藏）* |
| 11~16 | 格兰之森 · 格拉卡 | 格拉卡、烈焰格拉卡 |
| 14~24 | 天空之城（西海岸的云梯上去，Lv.14 起） | 龙人之塔、人偶玄关、石巨人塔、黑暗玄廊、城主宫殿、*悬空城（隐藏）* |

- 每个地下城有 4 个难度：**普通 → 冒险 → 勇士 → 王者**。通关普通解锁冒险，冒险评价 B 以上解锁勇士，勇士 S 以上解锁王者。难度越高怪越强、奖励越好。
- 门牌上的等级是推荐等级：红色 = 等级偏低，灰色 = 太简单。
- 主线跟着任务走就能一路升级；每天还有每日任务（布告栏等处）。

### 隐藏地下城

隐藏地下城的门平时看不见，完成对应的隐藏任务后，走到那片区域会看到门从天而降：

- **冰霜幽暗密林**：Lv.9 起，在旧城区找 G.S.D 接「寒气的源头」，去雷鸣废墟收集冰霜哥布林身上的寒气结晶。
- **暗黑雷鸣废墟**：Lv.14 起，从辛达的「辛达丢失的锤子」开始的一串任务。
- **悬空城**：天空之城的隐藏任务。

## 六、转职与觉醒

1. Lv.2 起林纳斯会给出试炼「格兰之森 - 杀手」：**被击不超过 30 次通关洛兰深处**。
2. 通过后去见自己的导师：鬼剑士找 **G.S.D**（旧城区），神枪手找 **凯丽**（中央广场），魔法师找 **莎兰**（魔法师公会）。
3. 跟着导师做七次修炼，Lv.15 的最后试炼是 **被击不超过 50 次通关烈焰格拉卡**。
4. 回到导师处，对话菜单里出现发光的 **转职** 按钮，选择你的方向：

| 职业 | 转职 | 风格 | 觉醒（Lv.21） |
|---|---|---|---|
| 鬼剑士 | 剑魂 | 近战 · 连击 | 剑圣 |
| | 狂战士 | 近战 · 爆发 | 狱血魔神 |
| 神枪手 | 漫游枪手 | 远程 · 连射 | 沾血蔷薇 |
| | 枪炮师 | 远程 · 重火力 | 重炮掌控者 |
| 魔法师 | 元素师 | 远程 · 范围 | 大魔导师 |
| | 战斗法师 | 近战 · 连击 | 贝亚娜斗神 |

5. 转职后按 **K**，在“转职技能”页学新技能，把图标拖到屏幕下方的技能栏。
6. **觉醒**：Lv.21 起导师会给觉醒任务（需要先解锁暗黑雷鸣废墟）：通关暗黑雷鸣废墟 3 次，再以 C 以上评价通关冒险级（或更难）烈焰格拉卡，并带 30 个无色小晶块，完成后解锁觉醒技能（放的时候有全屏插画）。
7. **二次觉醒 / 三次觉醒**：Lv.26 起导师给二次觉醒任务（冒险级以上通关天帷巨兽的炼狱 3 次，再以 C 以上评价通关极昼），完成后解锁二觉技能（Lv.26~27）；Lv.30 起给「真正的觉醒」（冒险级以上通关第二脊椎 2 次，再通关天帷禁地），完成后解锁三觉技能。没完成对应任务时这些技能不能学（技能窗口里会提示“需要完成二次觉醒任务”）。

## 七、决斗场

- 按 **P**，或去赫顿玛尔市政街找 **维尔·克鲁**。窗口里有两页：**排位赛**（要登录）和 **练习赛（AI）**。
- 三局两胜，每局 60 秒；时间到按剩余 HP 比例判胜负，一样就平局。
- **属性统一**：决斗场内属性统一，装备与强化不影响胜负。双方按职业 / 转职用同一套属性；技能等级统一按 30 级标准（和加点无关），觉醒全部可用、每局最多放一次。
- 有浮空保护、倒地保护、站立保护，连招越长硬直越短；HP 低于 25% 进入“燃斗”状态（攻击提高、受到伤害降低）。
- **排位赛**：点“开始匹配”，自动找积分相近的玩家；等 10 多秒还没人，就匹配一个 AI 对手（名字后面带「AI」）。
  - 段位：青铜 → 白银（1100）→ 黄金（1300）→ 白金（1500）→ 钻石（1700）→ 斗神（1900），新角色 1000 分；打过排位的角色，城镇名牌前会有段位小徽章。
  - 赢了加分、输了扣分，对手分越高赢了加得越多。AI 局只算一半分，白金以上赢 AI 不再加分——想冲高段位要打真人。
  - 同一个对手刚打过，5 分钟内不会再匹配到；开打后中途逃跑算输。
  - 奖励（发到邮箱）：每胜 2000 金币（AI 局 1000，每天前 10 胜）+ 5 点券（每天最多 30）；每天第一场胜利再加 5000 金币 + 20 点券。
  - 排行榜：排行榜窗口的“决斗场”页，或决斗场窗口里的“完整排行榜”。

## 八、和朋友一起玩（联机）
- **注册 / 登录**：打开网页版（https://dnf.cc.l-hate.com），标题画面点“注册”，填用户名、密码和房主给的**邀请码**。登录后进度存在账号的**云存档**里，换电脑、换浏览器登录都能接着玩；断网时先存在本机，恢复后自动上传。第一次登录时，如果这台电脑上有没登录时玩的角色，会问你要不要上传到账号。
- **看见彼此**：在同一个城镇场景里就能看到对方（名字、等级、职业、武器和时装）。名字颜色：橙色是队友，绿色是好友，蓝色是其他玩家。
- **点其他玩家**：弹出菜单——查看信息、私聊、加为好友、邀请组队、发起决斗。
- **聊天**：按**回车**打开聊天框，回车发送，Esc 收起；**Tab** 切换 世界 / 队伍 / 私聊。也可以打 `/w 名字 内容`（私聊）、`/r 内容`（回复私聊）、`/p 内容`（队伍）。打字时角色不会动。聊天框上面的“好友”“队伍”按钮打开对应窗口，右边是到服务器的延迟。
- **组队刷图**（最多 4 人）：队长走到地下城门口点“进入地下城”，队友不管在哪个城镇都会被一起带进去（需要疲劳够用）。房间一起换（谁碰到开着的门都行），怪物血量随人数提高（2 人 ×1.6、3 人 ×2.2、4 人 ×2.8）。**掉落和翻牌各拿各的**，经验每人都有。打完各自回到地下城门口。
- **好友决斗**：点玩家选“发起决斗”，或者在维尔·克鲁的决斗场窗口里选在线好友。三局两胜，双方属性由天平系统统一，**不影响装备和存档**，打完自动回城。
- **掉线**：会自动重连；20 秒内连回来可以接着打（错过的击杀奖励会补上）。队员掉线太久会离队，队长掉线太久大家回城，已经拿到的经验和物品都保留。
- **页面版本**：服务器更新后如果提示“版本不一致”，刷新页面就好；组队前大家最好都刷新一下。

## 九、更多玩法（登录后）

- **好友按钮**：左侧按钮条最上面的“好友”，输入对方用户名就能加好友；有新的好友申请时按钮上有红点。
- **公会（J）**：左侧“公会”。可以创建公会（需要金币，自选徽章）、申请加入；会长 / 副会长点其他玩家就能“邀请加入公会”。加入后名字上方显示公会名，还有公会频道、公会技能和商店。
- **成就（U）**：打怪、通关、社交、收集都会达成成就，在成就窗口“一键领取”奖励（点券、道具、称号）。
- **商城（]）**：右下角“商城”。点券全部靠游戏获得（升级、首次通关、评价、每日任务、成就）。可以买时装、宠物、光环、礼包，开魔盒（连续开有保底）。
  - **时装城镇移速**（只在城镇里生效）：每件装扮 +2%（天空套每件 +3%），集齐 8 件同套高级装扮合计 +30%，**8 件天空套合计 +60%**。个人信息（M）里能看到当前加成。
  - **天空套 8 件**：城镇里站着时，天穹圣翼背后展开光翼、炎龙之魂燃起火焰；走动时留下光羽 / 火焰脚印；名牌加一圈套装色的边框。
- **拍卖行（B）/ 邮件 / 签到 / 排行榜**：都在左侧按钮条。有新邮件时信封会闪，在地下城里也会显示信封。
- **深渊派对**：Lv.15 起找赫顿玛尔市政街的歌兰蒂斯接「深渊派对的资格」，通关烈焰格拉卡后交任务，拿到深渊派对邀请函；格拉卡区域左边会出现紫色的深渊门。每次进入消耗 1 张邀请函，打破封印之门、击退三波深渊派对后深渊领主降临，有几率掉史诗。天空之城尽头还有第二个深渊（通关城主宫殿后解锁）。
- **天帷巨兽**：Lv.24 起，从西海岸的码头坐船上去（神殿之路），Lv.27 起可以去脊背。

## 十、小技巧

- 进地下城前把 HP / MP 药剂放进 1、2 号快捷栏（物品栏里点药剂 → 选快捷栏位置，或直接拖到屏幕下方）。
- 有 SP 就去技能窗口加点；K 窗口里“+”升级，“−”降级返还 SP，右下角“重置技能”可以全部返还。
- 背包快满时去商店“出售 → 全选普通”一键卖掉白装。
- 用不上的装备可以在林纳斯 / 诺顿处 **分解** 成无色小晶块，拿去强化。
- 从地下城回来会站在那个地下城的门口，想再打一次直接往上走进门就行；结算时也可以点“再次挑战”。
- 画面太花：Tab 切换简洁界面，End 隐藏右下角评价，设置里能关屏幕震动和伤害数字。
- 设置里可以关掉“技能插图特效”“屏幕震动”“伤害数字”，画面会清爽很多；浏览器全屏（F11）体验更好。
