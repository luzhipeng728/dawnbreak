# 决斗场平衡（公正决斗 + 伤害修正 + 职业修正）

适用：排位赛、练习赛（AI）、好友决斗；**地下城不受影响**。代码：`src/game/duel.js`（`duelStats` / `duelKit` / `PVP_SKILL` / `PVP_JOB`）、`src/engine/combat.js`（`PVP`、`JUGGLE`）。浮空 / 倒地 / 受身蹲伏见 `docs/COMBAT_JUGGLE.md`，排位匹配见 `docs/NETWORK.md`。

## 1. 官方怎么做（调研）
- **天平 / 公正决斗场**（第七赛季起）：按转职给固定能力值，同一转职能力值相同；附魔、强化、增幅属性都不生效；同一武器类型攻击范围相同；后来还默认去掉了时装属性的附加伤害。
- **技能在决斗场单独调数值**：同一个技能在地下城和决斗场的伤害、效果分开设定（技能说明会按环境切换）；官方常在“决斗场技能平衡”里单独改某些技能。
- **保护**：浮空保护、倒地保护、平推保护、硬直 / 时间保护（连招越长硬直越短），见 COMBAT_JUGGLE.md。
- **命中**：决斗里双方按 100% 命中算（个别技能例外）。
- **燃斗模式**：HP 低到一定程度时攻击 +15%、受到伤害 −10%。
- **时间到**：按剩余 HP 判胜负。

来源：[DNF 官网 决斗场第七赛季](https://dnf.qq.com/cp/a20200716battle7/)、[DNF 官网 新手引导 · 决斗场](https://dnf.qq.com/act/a20121026gbook/pk.html)、[灰机 wiki 决斗场技能平衡性改版](https://dnfcn.huijiwiki.com/wiki/%E8%A7%92%E8%89%B2%E6%8A%80%E8%83%BD%E3%80%81%E5%86%B3%E6%96%97%E5%9C%BA%E6%8A%80%E8%83%BD%E5%B9%B3%E8%A1%A1%E6%80%A7%E6%94%B9%E7%89%88)、[DNF 官网 角色技能优化（2025）](https://dnf.qq.com/cp/a20250116skill/)、[DFO Arena Balancing](https://www.dfoneople.com/news/updates/1032/Arena-Update/Arena-Balancing)、[DFO World Wiki · PvP Mechanics](https://wiki.dfo.world/view/PvP_Mechanics)、[17173 保护系统](http://dnf.17173.com/content/02052016/103600707_all.shtml)。

## 2. 我们的规则
**公正属性**（`duelStats`）：只看职业 / 转职。HP / MP / 攻击 / 防御按职业固定（`DUEL_BASE`），等级 30，暴击 12%，攻速 / 施放 / 移速 1.0。
装备（含强化 / 增幅 / 锻造 / 宝珠 / 附魔 / 卡片）、套装、史诗 / 套装特效（`gear_fx.js`，含异界套的冷却与伤害特效）、时装 / 宠物 / 光环 / 称号 / 天空套 / 图鉴 / 公会加成、虚弱、消耗品和地下城里带来的 BUFF 全部不生效：
- 这些都只在 `recalcStats` / `equipTotals` 里算，决斗角色不走它（决斗中别的系统想重算也会被拦下）；
- `gearProcs / sets / mastery` 清空，`gearProcOk()` 在决斗里本来就关；
- 每局开始清空 BUFF / 异常；消耗品快捷栏在决斗中清空。

**满级 60 之后（2026-09-28）**：决斗等级仍固定 **Lv30**（`DUEL_CFG.lv`）。Lv60 角色进决斗也按 30 算；技能等级照旧按 `S.maxLv` 封顶，不吃 31~60 新加的技能上限（`skillMaxLv` 只用在技能窗口 / 地下城）。所以 `DUEL_BASE`、`PVP_JOB` 两张表继续有效，不用重跑循环赛；以后要改成 Lv60 决斗，得先按新技能等级重跑 `node test/pvp_balance.mjs 8 all`。

**觉醒取消**（2026-09-29）：和地下城一样，普攻和大部分技能中途能直接切入觉醒（没查到官方决斗场有额外限制）；决斗 AI 在自己的技能打中对手时有几率这样用。平衡复测见第 3 节。

**技能等级**（`duelKit`）：决斗等级 30 下本职业 + 转职能学的技能全部按标准等级 `1 + ⌊(30 − 需求等级) / 3⌋`（不超过满级），和 SP 加点、装备的技能等级无关；技能栏沿用玩家自己的摆放。觉醒（一 / 二 / 三觉）在决斗里全部可用、不看觉醒任务，每局最多一次（冷却至少 61 秒，每局开始清零）。AI 对手、联机两端都用同一套，两端算出的属性一致（`test/arena.mjs` 用 +12 史诗号和新手号核对）。

**伤害**：`伤害 × 0.35（PVP.dmg）× 技能决斗系数 × 职业修正`
- 技能决斗系数（`PVP_SKILL`，职业文件里写了 `pvp` 的以职业为准）：觉醒 0.5、抓取 0.8、召唤 0.8、爆发 0.85、范围 0.9、其他 1。
- 职业修正（`PVP_JOB`，AI 循环赛自动调出来的，`[造成, 受到]`）：未转职技能太少，鬼剑士 / 神枪手 [2.5, 0.55~0.65]、魔法师 1.7；阿修罗 [0.45, 1.15]、召唤师 0.5、机械师 0.62 / 弹药专家 0.58 最强势，被压得最多；漫游 / 枪炮 / 协战 1.15~1.4。
- **2026-09-29 技能范围按官方尺寸放大后重调**：放大范围让剑士整体涨 8~12 个点，三组分别压了自己的伤害倍率（当前数值以 `src/game/duel.js` 的 `PVP_JOB` 为准，本节下面列的是旧值）。复测 `pvp_balance.mjs 20`：18 个职业 38%~58%（未转职神枪手 2.5 → 2.8）。
- 连击硬直衰减：每多挨一下硬直 −2.5%，最低 60%。
- 时间到：剩余 HP 比例高的赢，一样就平局。

## 3. 平衡验证（`node test/pvp_balance.mjs 8 all`）
18 种职业 / 转职两两对打（AI 难度 3，每对 8 场左右互换，无渲染快进，约 40 秒）。回合胜率：
- 调整前：机械师 87%、阿修罗 69%、弹药专家 68% … 协战师 23%、未转职鬼剑士 9%、未转职神枪手 3%。
- 调整后（含新的浮空模型、合并 main 的霸体 / 无敌窗口修复后复测）：全部在 **44%~58%**，没有超出 35%~65% 的。
- 单个对局还有克制关系（每对只有十几回合，噪声大）：约 7/153 对超过 80%。
- 2026-09-29 觉醒取消 + 魔法师两个新被动（煌龙乱舞、强化-天雷）之后复测（`10` 场 / 对，跑了 4 次）：没有转职的职业和剑影 / 机械师掉到 36%~37%（能切觉醒的转职更占便宜），
  按最小改动上调 `PVP_JOB`：剑影 0.72 → 0.78、机械师 0.58 → 0.62、魔法师（未转职）1.58 → 1.7；复测全部在 **39%~61%**。

重新调参：`node test/pvp_balance.mjs 6 all 4`（自动迭代 4 轮后打印新的 `PVP_JOB`），贴回 `duel.js` 再跑一次 `8 all` 核对。改了技能 / 浮空 / AI 之后都应该重跑。

## 4. 男格斗家（2026-09-30，B9）
- **基准属性**：`DUEL_BASE.fighter` 和鬼剑士同一档（近战，官方四维和男鬼剑一样），强弱全在 `PVP_JOB`（当前数值见 duel.js；§5 新规则后整张表重调过）。气功师只压伤害要压到 0.3 以下（念气罩 1.9 秒无敌、龙虎啸 −10% 受伤、念气珠自动打人），所以同时调了受到的伤害（`[0.32, 1.3]`）。
- **决斗控制上限**（`PVP_CTRL`）：强制硬直 `hold`（格斗家组的“无视霸体硬直”）最长 1 秒，结束后 1.5 秒内不能再被 hold（和抓取保护 `PVP.grabProt` 一样）；束缚 `bind` 最长 3 秒。
- **持续伤害**：格斗家施加的毒 / 出血 / 灼烧 / 感电追加伤害在决斗里也乘 `PVP.dmg` × 自己的职业修正 × 对方的受到伤害（原来 `updateStatus` 直接扣血，街霸靠毒打出 88%）。
- **抓取公平**（`node test/fighter_pvp.mjs`）：AI 24 场里被放开后 1.5 秒内再被抓 0 次、一次最多被抓 ~3 秒（上限 4 秒）、hold 最长 1.00 秒、连续不能行动最长 < 8 秒（§5 时间保护）。
- **AI**（fighter_ai.js）：格斗家用整个技能池，要放的技能不在栏上就临时换进空闲 / 冷却中的格子；AI 会用全部主动技能（霹雳旋踢、鹰踏 / 空绞锤 / 裂石破天等空中技，抛投 / 浮空凌云踢按 ↓ 砸地再接霹雳旋踢）。
- **循环赛**：`test/pvp_balance.mjs` 网址默认带 `?fighter=1`（23 种 = 253 对），`FIGHTER=0` 只跑已开放的；`TUNE_ONLY=fighter` 只调这些前缀的数；调参下限 0.3。

## 5. 决斗规则重做（2026-09-30，用户：“两套技能就结束战斗”“追加浮空 / 一级二级保护 / 到底还能追加伤害”“大技能开局要有冷却，照官方”）
代码：`src/game/duel.js`（`DUEL_CFG` / `PVP_PROT` / `DUEL_START_CD` / `PVP_SUMMON`，包在 applyHit / castSkill / doAct / addStatus / resetCmb / spawnProj / summon / summonHit 外面，地下城不受影响）；测试 `node test/duel_rules.mjs`（每条规则一个单测）、`node test/duel_stats.mjs`（节奏统计）。

**官方资料**（决斗场保护系统，数值以端游 90 版以后的社区实测为准）：
- 平推保护（红条）：站立挨打累计 **20%~25%** HP → 强制倒地（[17173 Soldoros 五种保护](http://dnf.17173.com/content/2014-10-06/20141006021826085_all.shtml)、[52pk 连招保护计算](https://dnf.52pk.com/jingy/5993804.shtml)、[图老师 90 版保护条](https://www.tls999.com/n/20180421/2785898.html)）。
- 浮空保护（蓝条）：浮空后累计 **20%** HP 开始加速下落，**之后每 5% 再加重一级**；不会在空中直接站起，而是先落地（[52pk](https://dnf.52pk.com/jingy/5993804.shtml)、[17173 保护系统整理](https://dnf.17173.com/content/02052016/103600707_all.shtml)）。
- 倒地保护（黄条）：倒地后被追打累计 **15%~20%** → 不蹲伏直接起身、无敌 **0.7 秒**；**二次浮空**：落地后被再挑起来，伤害也算倒地保护，超过后落地直接站起（[52pk](https://dnf.52pk.com/jingy/5993804.shtml)、[17173 A6 破保护](http://dnf.17173.com/content/06232016/092248179.shtml)）。
- 硬直 / 时间保护：连招越长、对方硬直越短（手游决斗场：“连招补正，从空中、倒地、站立、时间四种方面”，[带你飞](https://www.dnfziliao.com/news/419.html)）。
- 状态保护：同一个技能打浮空的对手 **85%**、倒地 **90%~100%**（[图老师](https://www.tls999.com/n/20180421/2785898.html)、[52pk](https://dnf.52pk.com/jingy/5993804.shtml)）。
- 开局：**3、2、1 倒计时后开战**（[官网 决斗场第 8 季](https://dnf.qq.com/cp/a20230112pvp/)）；大技能有 **“起始冷却时间”**，而且基本 **= 这个技能的决斗冷却**（同页：疾刃之影 18 秒、黑夜之花 20 秒、回旋十字斩 25 秒、夜之风 30 秒、秘术·心斩 42 秒、行刑 42 秒；小技能大多没有，个别 5 秒）；手游是“无色技能开场自动进入冷却”（[带你飞](https://www.dnfziliao.com/news/419.html)）。
- 燃斗模式：按职业 20%~30% HP 触发，攻击 +15%、受到伤害 −10%（官网第 8 季；本作统一 25%）。

**平衡**：新规则下 `PVP_JOB` 整张表重调（`node test/pvp_balance.mjs 8 all 5` 自动 5 轮 + 手调出界的几项），20 场 / 对复测两次全部 **42%~60%**（第一次 43%~58%、第二次 45%~55%；格斗家 5 种 43%~55%）。

**线上问题（2026-09-30，“靠近阿修罗就一直被打在地上站不起来”）**：根因是阿修罗「无尽波动」每 0.5 秒直接调 `applyHit` 打周围的人（不走 `canHit`，倒地 / 无敌都不挡），打到倒地的人就走“倒地追击”分支把人托起 110 → 落地重新进入倒地、倒地计时清零；每跳伤害很小，倒地保护（20% HP）永远到不了，只能等 §5 的 7 秒时间保护，接着 AI 再打倒又是 7 秒。修法（所有职业通用，duel.js）：倒地的人只有追击判定打得到、起身 / 无敌中什么都打不中；倒地时间上限 1.6 秒；时间保护 7 → 3.2 秒并且到点主动脱出；硬控封顶 + 同种 2.5 秒免疫、倒地时挂的不拖延起身。测试 `node test/duel_wakeup.mjs`（狂战士走进开着无尽波动的阿修罗 4 局 × 45 秒：每次最多躺 1.6 秒、最长不能行动 3.6 秒；23 种职业 AI 轮流打人：最多躺 1.9 秒、最长不能行动 3.9 秒）。改后 `PVP_JOB` 又调了一轮，20 场 / 对两次 43%~58%。
