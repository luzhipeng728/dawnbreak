# 决斗场平衡（公正决斗 + 伤害修正 + 职业修正）

适用：排位赛、练习赛（AI）、好友决斗；**地下城不受影响**。代码：`src/game/duel.js`（`duelStats` / `duelKit` / `PVP_SKILL` / `PVP_JOB`）、`src/engine/combat.js`（`PVP`、`JUGGLE`）。浮空 / 倒地 / 受身蹲伏见 `docs/COMBAT_JUGGLE.md`，排位匹配见 `docs/NETWORK.md`。

## 1. 官方怎么做（调研）
- **天平 / 公正决斗场**（第七赛季起）：按转职给固定能力值，同一转职能力值相同；附魔、强化、增幅属性都不生效；同一武器类型攻击范围相同；后来还默认去掉了时装属性的附加伤害。
- **技能在决斗场单独调数值**：同一个技能在地下城和决斗场的伤害、效果分开设定（技能说明会按环境切换）；官方常在“决斗场技能平衡”里单独改某些技能。
- **保护**：浮空保护、倒地保护、平推保护、硬直 / 时间保护（连招越长硬直越短），见 COMBAT_JUGGLE.md。
- **命中**：决斗里双方按 100% 命中算（个别技能例外）。
- **燃斗模式**：HP 低到一定程度时攻击 +15%、受到伤害 −10%。
- **时间到**：按剩余 HP 判胜负。

## 2. 我们的规则
**公正属性**（`duelStats`）：只看职业 / 转职。HP / MP / 攻击 / 防御按职业固定（`DUEL_BASE`），等级 30，暴击 12%，攻速 / 施放 / 移速 1.0。
装备（含强化 / 增幅 / 锻造 / 宝珠 / 附魔 / 卡片）、套装、史诗 / 套装特效（`gear_fx.js`，含异界套的冷却与伤害特效）、时装 / 宠物 / 光环 / 称号 / 天空套 / 图鉴 / 公会加成、虚弱、消耗品和地下城里带来的 BUFF 全部不生效：
- 这些都只在 `recalcStats` / `equipTotals` 里算，决斗角色不走它（决斗中别的系统想重算也会被拦下）；
- `gearProcs / sets / mastery` 清空，`gearProcOk()` 在决斗里本来就关；
- 每局开始清空 BUFF / 异常；消耗品快捷栏在决斗中清空。

**满级 60 之后（2026-09-28）**：决斗等级仍固定 **Lv30**（`DUEL_CFG.lv`）。Lv60 角色进决斗也按 30 算；技能等级照旧按 `S.maxLv` 封顶，不吃 31~60 新加的技能上限（`skillMaxLv` 只用在技能窗口 / 地下城）。所以 `DUEL_BASE`、`PVP_JOB` 两张表继续有效，不用重跑循环赛；以后要改成 Lv60 决斗，得先按新技能等级重跑 `node test/pvp_balance.mjs 8 all`。

**觉醒取消**（2026-09-29）：和地下城一样，普攻和大部分技能中途能直接切入觉醒（没查到官方决斗场有额外限制）；决斗 AI 在自己的技能打中对手时有几率这样用。平衡复测见第 3 节。

**技能等级**（`duelKit`）：决斗等级 30 下本职业 + 转职能学的技能全部按标准等级 `1 + ⌊(30 − 需求等级) / 3⌋`（不超过满级），和 SP 加点、装备的技能等级无关；技能栏沿用玩家自己的摆放。觉醒（一 / 二 / 三觉）在决斗里全部可用、不看觉醒任务，每局最多一次（冷却至少 61 秒，每局开始清零）。AI 对手、联机两端都用同一套，两端算出的属性一致（`test/arena.mjs` 用 +12 史诗号和新手号核对）。

**伤害**：`伤害 × 0.35（PVP.dmg）× 技能决斗系数 × 职业修正`
- 技能决斗系数（`PVP_SKILL`，职业文件里写了 `pvp` 的以职业为准）：觉醒 0.5、抓取 0.8、召唤 0.8、爆发 0.85、范围 0.9、其他 1。
- 职业修正（`PVP_JOB`，AI 循环赛自动调出来的，`[造成, 受到]`）：未转职技能太少，鬼剑士 / 神枪手 [2.5, 0.55~0.65]、魔法师 1.7；阿修罗 [0.45, 1.15]、召唤师 0.5、机械师 0.62 / 弹药专家 0.58 最强势，被压得最多；漫游 / 枪炮 / 协战 1.15~1.4。
- **2026-09-29 技能范围按官方尺寸放大后重调**：放大范围让剑士整体涨 8~12 个点，三组分别压了自己的伤害倍率（当前数值以 `src/game/duel.js` 的 `PVP_JOB` 为准，本节下面列的是旧值）。复测 `pvp_balance.mjs 20`：18 个职业 38%~58%（未转职神枪手 2.5 → 2.8）。
- 连击硬直衰减：每多挨一下硬直 −2.5%，最低 60%。
- 时间到：剩余 HP 比例高的赢，一样就平局。

## 3. 平衡验证（`node test/pvp_balance.mjs 8 all`）
18 种职业 / 转职两两对打（AI 难度 3，每对 8 场左右互换，无渲染快进，约 40 秒）。回合胜率：
- 调整前：机械师 87%、阿修罗 69%、弹药专家 68% … 协战师 23%、未转职鬼剑士 9%、未转职神枪手 3%。
- 调整后（含新的浮空模型、合并 main 的霸体 / 无敌窗口修复后复测）：全部在 **44%~58%**，没有超出 35%~65% 的。
- 单个对局还有克制关系（每对只有十几回合，噪声大）：约 7/153 对超过 80%。
- 2026-09-29 觉醒取消 + 魔法师两个新被动（煌龙乱舞、强化-天雷）之后复测（`10` 场 / 对，跑了 4 次）：没有转职的职业和剑影 / 机械师掉到 36%~37%（能切觉醒的转职更占便宜），
  按最小改动上调 `PVP_JOB`：剑影 0.72 → 0.78、机械师 0.58 → 0.62、魔法师（未转职）1.58 → 1.7；复测全部在 **39%~61%**。

重新调参：`node test/pvp_balance.mjs 6 all 4`（自动迭代 4 轮后打印新的 `PVP_JOB`），贴回 `duel.js` 再跑一次 `8 all` 核对。改了技能 / 浮空 / AI 之后都应该重跑。
