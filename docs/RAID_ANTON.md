# 团本 · 安徒恩攻坚战（Neo 版，Lv60）

状态：现行。规则 `src/game/raid_anton.js`（`RAID_DEFS.anton`，服务端同文件加载）；内容 `src/content/raids/anton_raid.js`；奖励 `src/content/items/raid_anton.js`。
测试：`test/anton_rules.mjs`（规则）· `test/anton_bosses.mjs`（领主 / 精英逐个 + 地下城登记）· `test/anton_ui.mjs`（浏览器冒烟）。

## 来源与可信度

资料来自子智能体调研 + 一次网页检索（玛特伽 / 心脏），**大多未核实**。标注：
- **[研]** 调研资料；**【存疑】** 数字 / 顺序没确认；**【原创】** 没有资料，按官方风格补；**【改编】** 官方玩法在本项目里换了实现。

## 档位

| 档位 | 人数 | 说明 |
|---|---|---|
| guide | 1 | 节点精简（单个黑雾之源 / 震颤 A / 擎天之柱 2 次 / 孵化所 1 个 / 心脏 1+核心） |
| duo | 2 | 每人一支单人队 |
| team | 4~16 | 4 队 × 4 人；`par(nt)` 缩放时限 |

引导削弱：机制强度 ×0.6（`scale.guide.mech`）；精英破防参数减半（机制球 4→2、电球 3→2、分身 3→2、龟壳 3→2、惩罚减半）；精英“护盾”是减伤不是无敌，等同官方的霸体护甲思路；内尔贝电球数 = 人数相关（`anOrbN`：`max(3, min(6, ⌈人数/2⌉))`，引导 2）；玛特伽「打字」机制球 4 → 2（`anBallN`）。

## 流程

### P1 阻截战（限时 70 分钟 / 引导 40）
1. **黑雾之源 ×4**（`fog_a~d`，同一张图）：精英**吞噬魔**（属性球，[研]）+ 领主**歼灭之内尔贝**（雷阵撤离 / 蓝色电球每人拦一颗 / 落雷躲角落罩子，[研]）。精英击杀 = 全团攻击 +4%（【原创】数值）。
2. **震颤的大地 A / B**（倒计时 360 秒，通关修复 120 秒；到 0 = 最靠后已开放的一层回退、时间不退，[研]）：A = 毁灭之塔伊奥利（精英红色加血球 = 拦截）；B = 湮灭之弗雷伊内斯（炔药柱眩晕；玩家幻影读条前杀完 = 击杀分身）。精英倒下延缓倒计时。
3. **舰炮防御战**（`cannon`）：官方「守右侧炮充能 3 次，变红禁用无色技能」。【改编】：登舰突击队长，血量 75/50/25% 三次「舰炮充能」输出窗口，未完成 = 舰炮故障（灭团）。【原创】领主。
4. **擎天之柱 A / B**（各打 2 次：A-1→A-2、B-1→B-2）：炽炎之艾格尼丝，精英灼眼 = 睁眼禁攻（eyeGuard），领主 = 睁眼反射 + 杀分身进输出窗口，[研]。目标 = A-2 + B-2。

### P2 焦杀战（限时 60 分钟 / 引导 30）
1. **能量阻截战**（`egale`）：杀黄色精英**吞噬之厄伽勒** → 四个孵化所 + 紫色感染孵化场开放（`unlock`）。【改编】厄伽勒用属性球玩法；守卫领主「能量核心守卫」【原创】。
2. **四个孵化所**（各自分头）：熔岩怪虫（破龟壳）/ 巡视者梅尔塔（引导球体破坏发电机 → 拦截球）/ 粉碎者阿托尔（领域战 → 破招）/ 恐怖邪念体（找实体 → 击杀分身），[研]，具体破防参数【原创取舍】。共用领主「孵化所守卫」【原创】。
3. **紫色感染孵化场**：没清除期间，火山（有人在里面打时）每 30 秒叠一层护盾（`def` +8%，最多 6 层）；清除后撤掉，[研]，数值【原创】。
4. **黑色火山**：全能之玛特伽 [研][存疑]：常驻无敌反伤罩；上勾拳瞬间罩子消失 → 打它吐出金 / 土 / 血 / 风珠 → 引到魔法阵 → 召唤对应精英 → 虚弱；二阶段随机火 / 冰 / 光 / 暗属性技能。实现：`orbs`（四色球）+ `dps`（破招窗口）；二阶段属性技能 = 圈 / 雨 / 激光。【改编】没做“召唤对应精英”。
5. **安徒恩的心脏 ×5**（前 4 颗各自分头，第 5 颗整队）：资料只说“无复杂机制，纯输出”，**招式全部【原创】**：左心房（血栓掩埋）/ 右心房（血压聚集槽）/ 主动脉（朝向冲击）/ 静脉丛（路线迷宫）/ 核心（心跳震荡 + 掩埋 + 栓塞清除 + 输出窗口）。
