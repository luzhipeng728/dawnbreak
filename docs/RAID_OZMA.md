> 状态：现行。规则在 `src/game/raid_ozma.js`（`RAID_DEFS.ozma`，服务端同载），内容在 `src/content/raids/ozma_raid.js`、`src/content/regions/ozma.js`，HUD 在 `src/ui/raid_ozma.js`，奖励在 `src/content/items/raid_ozma.js`。
> 标注：【官方】有来源；【存疑】来源只有一处或互相矛盾，取舍写明；【原创】查不到，按官方风格自己设计。
> 调研大多未核实：下面「官方」只表示取自方案 `raid_redesign_plan.md §4.3` / `RAID_PLAN.md §2` 的描述（DFO:Ozma_Raid 及国服攻略的转述），没有逐条回源。

## 2. 地图与节点（规则核心节点图，18 张地图全部使用）

地图 id 对应 `OZMA_CORE`（`src/game/ozma_core.js`，独立状态机保留给它自己的测试）里的 18 张，dungeon id 为 `ozma_<地图 id>`。每区 5 张：**钥匙图 → 两张主线图 + 一张功能图 → 主领主**。

| 区域（色调） | 钥匙图 | 主线图 | 功能图（通关效果） | 主领主 |
|---|---|---|---|---|
| 毁灭（红） | `ruin_path` | `ruin_resting`、`ruin_gladden`（**双剑图**：混沌 +1） | `ruin_corridor` = **亡者回廊**：全团打领主伤害 +12%（`dead_hall`，`dmgTaken 1.12`） | `ruin_beyond` = **贝利亚斯** |
| 绝望（蓝紫） | `despair_crossroads` | `despair_aventus`、`despair_phylis` | `despair_serha` = **赛赫**：理智上限 +30、缓慢恢复（`sanMax 30 / sanRegen 1`） | `despair_lunen` = **提亚马特** |
| 恐怖（黑绿） | `terror_land` | `terror_grauben`、`terror_eldfell`（**双剑图**：混沌 +1） | `terror_red_altar` = **赤红乐园祭坛**：点亮得钥匙 `altar` | `terror_martyr` = **卡赞**（要钥匙 + `altar`） |

- 钥匙图通关得该区钥匙（`key`），主线图要先有钥匙图；主领主要两张主线图都通关 + 钥匙（卡赞还要 `altar`）。功能图是**可选**的增益图（通关后不重生：`respawn: 0`；规则上状态是「冷却」而不是「通关」，所以不作为前置，只给效果）。
- 卡赞无敌：门槛 = 没点亮祭坛不让进（`needKey: altar`）；进去后机制 `ozmaLock{floor:1, unlockKey:'altar'}` 再兜一层（会话里没有 `altar` 钥匙时领主不掉血）。
- 引导图（`graph:'guide'`）：每区只留 钥匙图 / 第一张主线 / 领主（9 张），没有功能图、双剑图、倒计时图；混沌固定 1。
- P2：**埃利诺斯倒计时图**（`p2_elerinon`，`type:'timer'`，420 秒，通关修复 150 秒）、**阿斯特罗斯所在图**（`p2_armis`）、**混沌王座**（`p2_throne`，`final`，共享血量存档点 `cp`，`need: []` 任何时候可进）。
  - 埃利诺斯：倒计时到点没压制 = 炸团：阿斯特罗斯所在图进度重置（`reset areas:[1]`，里面的队伍踢回营地）+ 全团理智 −15；精英「压制者」被击杀 = 倒计时重置（`countdown`）；通关 = 全团增伤 +15%（150 秒）。
  - 阿斯特罗斯所在图通关 → 全团增益 `ozmaUnlock`（直到团本结束）→ 奥兹玛锁血解除。
  - 奥兹玛 50% 锁血：领主机制 `ozmaLock{floor:.5, unlockGbuff:'ozmaUnlock'}`，血量压到 50% 不再下降（受伤倍率 0），提示去阿斯特罗斯图；引导 / 没有会话时不锁。
  - **轮转**：三队按 奥兹玛 → 埃利诺斯（清夜）→ 奥兹玛 → 阿斯特罗斯 → 奥兹玛 的顺序换队打同一个共享血量的奥兹玛（每队进出靠存档点续血）。**规则核心不强制顺序**，只给 `cp` 续血 + 锁血 + 解锁；顺序是团队指挥用的团长标记（`mark`）。【存疑：「清夜」官方含义未核实，这里按「压制埃利诺斯那一轮」解释】
- 领主名：规则清单里 `ruin_beyond` 原名「超越者卡赞」、`despair_lunen`「月蚀之鲁恩」、`terror_martyr`「殉道者」、`p2_armis`「阿尔米斯」，在团本里（`ozmaBoss`）显示为贝利亚斯 / 提亚马特 / 卡赞 / 阿斯特罗斯。`ruin_path` 仍是「毁灭之王卡赞」的幻影（`ozma_runtime` 测试的断言）。
- 【存疑 / 原创】区域—主领主、功能图归属、「双剑图」是哪两张：官方只有「亡者回廊加伤害 / 赛赫理智 / 赤红乐园祭坛解卡赞无敌 / 双剑图提混沌等级」这四个功能的描述，没有逐图对应，这里按各地图名字就近分配。
- 营地：`ozma_town`（圣者之地）。军需官 NPC（混沌军需官）带「团本」入口 + 攻坚商店 `ozma_raid`（金币结算，货币走奖励）。

## 3. 理智值（官方）

- 初始 100；机制攻击（被领主 / 精英 / 机制打中）降低；赛赫提高上限和恢复。
- 第一次归零 → 进入小游戏房间，完成后恢复到 50；第二次归零 → 倒下。规则：`RAID_DEFS.ozma.sanity { max:100, restore:50 }`，核心 `sanityAdd`（上限 = max + 全团增益 `sanMax`）；事件 `san`（自己报，单次限幅 ±40）。
- 扣减：客户端 `bus playerHurt` → 按伤害占最大血量的比例 `min(12, dmg/hpMax×40)`，混沌等级每高 1 级 ×1.15，累积 ≥1 才上报（【原创】数值）。赛赫：每 2 秒 +`sanRegen`。
- HUD（`src/ui/raid_ozma.js`）：屏幕边缘暗角（理智越低越黑）+ 理智 < 50 后给世界画布挂 SVG 扭曲滤镜（`feTurbulence + feDisplacementMap`，位移随理智线性加大）、理智条、混沌等级徽记。「小游戏房间」做成覆盖层：5 个混沌符文按 1→5 点亮，点错重来，完成才继续（游戏暂停期间）【原创：官方是传送到小游戏房间】。倒下 = 玩家 hp 清零（走正常倒下 / 复活币流程）。

## 4. 混沌等级（官方）

1~3 级，起始 1；双剑图通关 +1（规则 fx `chaos`）。越高奖励越多：货币 ×`[1, 1.3, 1.7]`（`D.chaos.cur`，核心 `rollReward` 乘算）；理智扣减也更重。【原创】倍率；官方「等级越高奖励越多、难度也更高」，未做敌人数值缩放（只通过理智压力体现）。

## 5. 小怪 / 精英（真实技能 + 破防）

- 区域小怪沿用 `OZMA_MOBS`（8 种，各带真实技能：前冲 / 追踪弹 / 扇射 / 瞬移 / 砸地环 / 激光 / 召唤）。【原创】
- **门将**（`ozma_gate_<区>`，每区一套专属技能，抬手 / 前冲就是破招要打断的东西）：
  | 门将 | 技能 | 破防（`defineRaidElite`） |
  |---|---|---|
  | 毁灭 `ozEliteRuin` | 格挡、砸击、**前冲**（抬手 1 秒）、黑焰扇射 | **破招 counterBreak**：每 9 秒起手 2.4 秒，1.5~2.2 秒是闪光窗口，窗口内命中 = 打断 + 硬直破防（受伤 ×1.6，7 秒）；没打断 = 招式落下（全团 25%） |
  | 绝望 `ozEliteDespair` | 格挡、砸击、追踪弹、十字光柱、召唤残灵 | **拦截 intercept**：绝望之球飞向它，连续拦截 4 个破防，漏球回血 |
  | 恐怖 `ozEliteTerror` | 格挡、砸击、震地环、岩刺雨、**冲锋** | **破壳 breakShell**：岩壳 3 块各 4 下，全碎破防，20 秒后重生 |
  | 埃利诺斯压制者 `ozEliteSuppress` | （复用恐怖门将） | **击杀分身 killClone**：读条时刷分身，杀光打断；击杀 = 倒计时重置 |
  | 王座门将 `ozEliteChaos` | （复用恐怖门将） | 破招，更快（7 秒 / 窗口 0.6 秒 / 惩罚 35%）；阿斯特罗斯图 + 奥兹玛图 |
- 击杀门将：全团理智 +10。以上破防种类和数值均【原创】；框架来源 `docs/RAID_FRAMEWORK.md §3`。

## 6. 领主机制（`OZMA_RAID_SCRIPTS`，每个领主一份脚本，`raid_mech` 的 raidScript）

18 个领主都有脚本：定时机制招（`atk`：全屏击倒 `crouch` / 掩埋 `burial`）+ 血量门槛读条的虚弱谜题（`weak`：封印 `clear` / 顺序踩板 `pads` / 属性球 `orbs` / 引导火种 `guide` / 水晶 `crystals` / 心跳 `heartbeat` / 日月之剑 `swords` / 限时输出 `dps` / 搬运 `gem`…），没解开 = 灭团（按各自 `onFail`），解开 = 领主虚弱（受伤 ×1.5~1.6）。逐个领主的具体谜题见 `src/content/raids/ozma_raid.js`，对应关系取自 `OZMA_CORE` 各图的 `mechanics` 描述（【原创】谜题选型）。

重点：
- **阿斯特罗斯（`p2_armis`）· 三扇次元之门**（`doors`，`src/game/raid_ozma_mech.js` 往 `RAID_MECH.PUZ` 登记）：血量 75% / 50% / 25% 各读条一次。她依次穿过其中两扇门（头顶「穿过 1 / 2」，另一扇「？」，前 3.2 秒提示），6 秒后秒杀判定：**只有站在她最后没穿过的那扇门里的人躲得过、且使她虚弱**；站错的被击倒；没有人躲进 = 灭团。【存疑：官方「进她最后没通过的那扇门」的具体判定未核实，这里这样落地】
- **奥兹玛（`p2_throne`）**：混沌审判（全屏击倒）、混沌锁链（掩埋）；80% / 62% / 30% 读条混沌球 / 混沌领域；50% 锁血（见 §2）。
- **卡赞（`terror_martyr`）**：罪火审判 / 神焰爆发；祭坛点亮前无敌；誓约火种引导 + 破除神焰。
- 区域内领主的招式（`OZMA_ATTACKS` 按图轮换）沿用区域规格里的；这里的 `raidScript` 只增加机制层。

## 7. 规则核心接入

- `ozma_core.js` 的独立状态机只作参考与旧测试；会话、分队、计时、领奖、每周次数、建团全部走 `raid_core.js`（服务端 `server/modules/raid.js` 加载 `ozma_core.js → raid_core.js → raid_ozma.js`），UI 入口在阿甘左 / 混沌军需官的「团本」窗口（`RAID_AREA.ozma`：P1 三列、P2 两列），建团按钮：两人 / 多队 / 单人引导。
- `raid_core.js` 的唯一改动：`sanityAdd` 的上限加上全团增益里的 `sanMax`（赛赫）。
- 新节点字段 / 效果全部用已有的：`key` `func` `timer`、fx `key / chaos / gbuff / reset / countdown / sanity`、`needKey`、`elites`、`cp`。
