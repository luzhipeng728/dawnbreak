## 1. 两人版的总原则（主线程定的默认决策）

- **保留 2 人上限**，但**官方全图一张不删**：16 人 4 队同时打的图，两个人轮流打（分头 / 先后）。
- **惩罚按比例缩放**：跨图叠层的数值 × `scale.normal.pen = 0.5`（两人 ≈ 官方一队的一半人手）；引导模式 `pen = 0`、`penalty = false`（没有跨图惩罚）。
- **并行时限 ×2**：官方 4 队同时打的共享时限，两人版翻倍（破坏之门 5 分钟 → 10 分钟、真理之棺 8 分钟 → 16 分钟、阶段 40 分钟 → 80 分钟）。单张图自己的时限（黎明 7 分钟、忘却 5 分钟、阴影之棺 30 秒）不变。
- **数值都是数据**：`RAID_DEFS.siroco` 里的数字可以写 `{ normal, guide }`，换一种来源的取值只改数据，不改代码。
- **来源冲突时取官方普通模式**（国服官方版本页 [QQ] 优先），另一种取值写在 §6。

| | 压抑（suppress，迷雾中的暗杀者凯恩） | buff | 通关一次 → 真理之棺顺时针转 120°；重生 30 秒 [QQ][NAMU-C1] | `{ kind: 'rotate' }`；4×4 迷雾网格，领主在外圈“┛”7 房之一 |

**共享血量的同步**：主机每掉 1% 报一次 `hp`；服务端把“这次挑战自己打掉的”从池子里扣掉，再把池子和每个挑战当前血量的差值推给它们（`pool` 推送，客户端按差值加减领主血量），任何一边打空 = 所有真理之棺 + 阴影之棺一起通关。防作弊：共享血量按 `guard.maxDrop`（5%/秒）封顶，多报的部分下一次同步补回给客户端。

## 4. 引导模式（单人）

保持原来的引导图：阻截战 `破坏之门 → 梦幻之黎明 → 记忆的碎片 → 无形之门（双领主一个房间）`，讨伐战 `无欲之棺 → 意识之棺 → 真理的意识之棺`（有存档点）。没有共享时限、跨图惩罚、共享血量。复活币每人每图 4 枚 [QQ 引导]。

## 7. 规则核心新增的字段（`raid_core.js` 文件头有完整说明）

`needEnter` / `needBoss`（新的客户端事件 `boss`，服务端 `EVS` 也加了）/ `manual` / `groupLimit` / `runLimit` + `kickEro` / `failKick` / `failReset` / `aura` / `pool` + 阶段 `pools` / `slot` + 阶段 `rot` / `enterFx`；
效果新增 `stack` / `reset` / `rotate` / `merge`，`buff` 的 `dur: 0` = 直到目标通关，`groggy` 的 `ifBoss`；`respawn: 0` = 不重生；`perNode` / `lives` 可以按模式写。
`view()` 多给了 `pools` / `glim` / `aura`（每个节点的叠层数）/ `rot`（当前形态、是否共鸣）。`shift()`（服务端重启顺延）覆盖所有新计时。
