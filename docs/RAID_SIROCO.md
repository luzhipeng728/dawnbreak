## 1. 两人版的总原则（主线程定的默认决策）

- **保留 2 人上限**，但**官方全图一张不删**：16 人 4 队同时打的图，两个人轮流打（分头 / 先后）。
- **惩罚按比例缩放**：跨图叠层的数值 × `scale.normal.pen = 0.5`（两人 ≈ 官方一队的一半人手）；引导模式 `pen = 0`、`penalty = false`（没有跨图惩罚）。
- **并行时限 ×2**：官方 4 队同时打的共享时限，两人版翻倍（破坏之门 5 分钟 → 10 分钟、真理之棺 8 分钟 → 16 分钟、阶段 40 分钟 → 80 分钟）。单张图自己的时限（黎明 7 分钟、忘却 5 分钟、阴影之棺 30 秒）不变。
- **数值都是数据**：`RAID_DEFS.siroco` 里的数字可以写 `{ normal, guide }`，换一种来源的取值只改数据，不改代码。
- **来源冲突时取官方普通模式**（国服官方版本页 [QQ] 优先），另一种取值写在 §6。

## 10. 领主机制系统（P2，`src/game/raid_mech.js` + `src/game/raid_mech_rt.js`）

- **两层**：`raid_mech.js` 是纯逻辑（不碰 DOM / 实体，只吃事件、吐事件，node 直接 `require`，固定种子可复现）；`raid_mech_rt.js` 注册领主机制 `raidScript`，
  把世界翻译成事件（本机玩家位置 / 朝向 / 蹲下 / 连打、领主位置、打到 / 打碎物件、被打中），再把输出翻译回世界（刷物件、画地面标记、挨打、状态、读条条）。
  新谜题只写规则和数据（`objs` 要打的物件、`marks` 地面标记），画面和输入是通用的。
- **领主脚本**（写在领主的 `mechs: [{ use: 'raidScript', ... }]`）：
  `intro`（出场无敌，默认 2.5 秒，≤ 3 秒保证机器人 / raidfast 能打）→ 战斗（可选 `loop` 固定出招循环、`atk` 定时机制招）→
  `weak.at` 血量门槛 / `weak.every` 定时读条，从 `weak.pool` 虚弱池抽谜题（`pick: 'cycle' | 'random'`）→ 解开 = `onSolve` 虚弱（默认 8 秒、受伤 ×1.5）；
  没解开 = `onFail` 灭团（默认按最大 HP 100%，打倒；**引导模式最多 30%**）。读条 / 虚弱 / 出场时领主站着不动。`lines` 台词（入场 / 读条 / 解开 / 失败 / 残血）。
- **谜题原语**（默认值都在 `PUZ.<id>.defaults`，挨打按最大 HP 比例 × 难度系数，引导模式挨打 ×0.5、时限 ×1.25）：

| id | 玩法 | 解开 / 失败 |
|---|---|---|
| `pads` | 顺序踩板（开头 `peek` 秒显示序号，之后凭记忆） | 踩完 / 错 `maxWrong` 次以上或超时 |
| `heartbeat` | 心脏发光时打它（每拍算一次） | 打满 `need` 拍 / 超时；不亮时打 = 挨打 |
| `realBody` | 分身里只有一个周期性闪光 | 打到真身 / 打错 `maxWrong` 次以上 |
| `orbs` | 按领主给的属性顺序打碎属性球 | 打完 / 超时；打错 = 挨打、全部复原 |
| `path` | 只能走发光的地板 | 走到对面 / 掉下去 `maxFalls` 次以上（掉下去回起点） |
| `guide` | 引导光球进祭坛（走近它会跟着你） | 全部送到 / 超时 |
| `burial` | 一人被埋（定身），连打攻击挣脱 / 队友打墓碑 | 挣脱 / 到点重伤 45% |
| `tether` | 和领主连线，离太近持续挨打 | 撑过 `dur` / 挨打 `maxBad` 次以上 |
| `breath` | 呼吸槽：离开气泡会掉，见底窒息 | 撑过 `dur` / 窒息 `maxBad` 次以上 |
| `reflect` | 反射罩亮着时打领主 = 反伤（领主只受 30%） | 撑过 `dur` / 反伤 `maxBad` 次以上 |
| `gem` | 搬宝石到祭坛（减速，被打中会掉） | 全部送到 / 超时 |
| `crystals` | 限时打碎水晶 | 打完 / 超时 |
| `swords` | 领主亮出日 / 月，站到对应的剑旁边 | 撑过 `rounds` 轮 / 站错 `maxMiss` 次以上 |
| `facing` | 背对 / 面朝领主（`random` 每次随机） | 结算时朝向对 |
| `soulSwap` | 身上带日 / 月之魂，只能打同色的魂，中途互换 | 打碎 `need` 个 / 超时；打异色 = 挨打 |
| `souls` | 守门人之魂只在 **BGM 节拍**（钟声 + 闪屏）后的窗口里能打碎 | 全部打碎 / 超时；节拍外打 = 反伤 |
| `crouch` | 全屏击倒：**只有蹲下（按住 ↓）能躲**，跳起来也会被打倒 | 结算时蹲着 |
| `dps` | 限时打出领主最大 HP 的 `need` 比例（绝望技 / 魅惑之舞 / 弹球） | 打够 / 超时 |
| `clear` | 站进地上的阵 `hold` 秒消掉（会定时再长、会变大） | 全部消掉 / 超时（`failHurt` 再挨一下） |
| `feed` | 领主头顶显示一个属性，打碎**相反属性**的球喂给它（火↔冰、光↔暗） | 喂对 / 喂错或超时 |
| `gauge` | 天上的泡泡慢慢聚集，被领主打中会加速；满了全场挨打 | 撑过 `dur`（挨打 `maxBad` 次以上算失败） |
| `absorb` | 轮流进气息柱吸气，头顶条满了还在里面 = 大爆炸 | 吸够 `need` 秒 / 爆炸 `maxBad` 次以上 |

- **谜题公共选项**：`onSolve` / `onFail` / `cast` 覆盖脚本的同名设置（`onSolve.dur: 0` = 只化解、不虚弱，给官方没有破防的领主）、`failHurt`、`skipGuide`（引导模式跳过）；
  `path` 另有 `noJump`（跳起来也算踩空）、`rtl`（从右往左）、`grace`（亮起后 0.8 秒才判定，开始时所有人送到起点）；`guide` / `gem` 的 `toBoss`（目标是领主本人）；`realBody` 的 `rounds`（连续认出几次真身）。
- **脚本另有**：`orderCue`（守门人：约 36 秒按这扇门的击杀顺序换 BGM 乐器）、`loop` + `rest`（蕾娜：固定出招循环，每招后回中央黑雾站着、受伤 ×1.3）、
  `atk` 定时机制招（不打断战斗，和读条可以同时出现）；进场时共享血量已经低于某个门槛就跳过那个门槛。

- **玩家状态**（`STATUS`）：叠层 / 计时 / 满层触发（侵蚀 5 层 → 石化、寒气 3 层 → 冰冻），`eff` 翻译成游戏异常（定身 / 减速 / 眩晕 / 失明）。
- **蹲下**：不改引擎，`raid_mech_rt.js` 读 `input.heldFor('down') > 0.12` 且在地上；机器人 / 测试可以直接设 `p.raidCrouch`。
- **限制（还没做）**：脚本只在主机跑，组队“一起进”的节点里队员那边看不到谜题物件 / 标记（伤害照常走主机的领主）；两个人同屏时谜题只认主机玩家。
- **测试**：`node test/raid_mech_core.mjs`（纯逻辑，72 项：每个谜题的解法 / 错法、状态、脚本流程、同种子一致）、
  `node test/raid_mech_lab.mjs`（浏览器实验室，样品怪挂脚本：每个谜题真的刷物件 / 标记并按解法解开、出场无敌、灭团掉血、掩埋定身、蹲下躲击倒、BGM 节拍、领主倒下时收尾、HUD）。

- 哈妮尔的“传心”（红心在玩家之间传递、持心者才能消分身阵）→ 两人版谁都能消阵（定时机制招 `clear`）。
- 崔拉 & 昙娜的两个球官方是两名玩家各引一个、连线交叉 → 两人版一个人可以把两个都引到中间。
- 卢克西的吸血（多人站位挡黄血）两人做不了 → 没做；共鸣 / 宝玉撞击保留。
- 维塔 / 奈克斯“慈悲 / 公义的引导”能量球个数取 3（困难难度描述）；NAMU 写 4 → 改 `n` 即可。【分歧】
- 明皓的招式两组来源差异很大，取 [YW-昼] 为主（召唤玄武束缚 + 齿轮必杀），[NAMU-WIT] 的另一套没做。【分歧】

- 守门人 BGM 乐器对应的顺序取 [NAMU-LAW]；没有门顺序（单张练习）时只提示“BGM 换了乐器”。
- “全屏击倒只能蹲伏躲”没改引擎：按住 ↓ 0.12 秒以上且在地上算蹲下（跳起来也会被打倒）。

**限制（还没做）**

- 脚本只在主机跑：组队“一起进”的节点里，队员那边看不到谜题物件 / 地面标记（领主伤害照常同步），谜题只认主机玩家的位置。
- 智力之门（哈妮尔那条线）的跨图惩罚按 P1 的光环做；[YW-昼] 描述的“日 → 黎明爆炸圈”变体没做（只差 `raid_core` 光环里加一种 `circles`）。

## 12. 子弹时间「无之轨迹」和其他表现（P4）

- **官方**：只有小队队长能用（按 Tab），能量在领主房积累，开启后除本队以外的一切都变慢；攻略里几乎每个机制都写“队长用无之轨迹延长机制时间” [QQ][233-黎]。
- **两人版**：每个人都是自己小队的队长。有团本脚本的领主房里能量自动充（`RAID_BT.fill` = 60 秒充满，出场无敌时不充），**按 7**（按键设置 → 其他，可改键；Tab 已经是“切换界面显示”）开启，
  `RAID_BT.dur` = 5 秒内**怪物 / 领主 / 机制计时 × 0.35**（读条时限、虚弱都跟着延长，约多出 3 秒），玩家不受影响；领主 HUD 下面有能量条（就绪时变金色）、开启时全屏偏紫 + 暗角、钟声。
  维塔的虚弱不能延长（`btNoBreak` [NAMU-PAIN]）。
- **引擎改动**：`game.js` 的实体循环加了一个只给敌方实体的 dt 倍率（`game.monSlow` / `game.monSlowT`，到点自己失效），没碰 combat / entity。
- **限制**：组队同房（团本“一起进”/ coop）不能用（要主机同步，以后做）；已经飞出来的怪物弹道和地面预警不变慢；手机没有按钮。数值都在 `RAID_BT`。
