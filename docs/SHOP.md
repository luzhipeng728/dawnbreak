# 破晓地下城 · 商城与礼包设计（商城组）

用户原话：“这一套是玩法的最好的一个地方，能够开出各种好东西，盒子，什么的，这块帮我好好的搞好点，各种好东西”“开箱子能够开出的东西可以更多点，更加深入的弄，多加点东西”。
硬性规定：**不涉及真钱**。点券全部靠玩游戏获得。

本文是实现依据。数值以代码为准：`src/content/cash/catalog.js`（商品、价格、奖池、产出）、`src/content/cash/items.js`（物品）。游戏里的“概率公示”页直接读奖池数据生成，和本文一致。

## 0. 名称来源
按官方 DNF 的叫法来（调研见文末）：
- 点券、魔盒、装扮合成器 / 黄金装扮合成器 / 梦想装扮合成器
- 高级装扮 / 稀有装扮（天空）
- 宠物装备（红 / 蓝 / 绿）、光环、武器装扮、宝珠、至尊称号 / 至尊宠物、多买多送、不放回抽奖（官方 2022 起的“奖池 20 种奖励，每套 2 次，10 套抽空”）

具体套装、宠物、称号的名字是原创的，按官方风格起。

## 1. 货币

| 货币 | key | 存放 | 用途 |
|---|---|---|---|
| 点券 | `cera` | `save.data.cera` | 商城主货币 |
| 魔盒碎片 | `shard_box` | `save.data.shop.shard` | 每开 1 个魔盒得 1 个，在碎片商店兑换 |
| 礼包币 | `coin_gift` | `save.data.shop.gcoin` | 节日礼包附赠，在礼包币商店兑换 |

- 三种都是**计数型**：`giveItem(makeItem('cera', 500))` 会直接加余额，不占背包格子，和复活币 `coin` 一样。
- 函数：
  - `addCera(n, 来源)`：加点券，写流水。
  - `spendCera(n, 原因)`：扣点券，余额不足时返回 false。
  - `cashBal(货币)`：查余额。
- 数据都在角色存档里，懒初始化 `save.data.shop ??= {...}`，登录后随云存档同步。

### 1.1 点券来源（`CASH_EARN`）

| 来源 | 数额 | 限制 |
|---|---|---|
| 升级 | 新等级 × 40（Lv2 得 80 … Lv30 得 1200） | 一次性，Lv1→30 合计约 1.9 万 |
| 首次通关 | 每个地下城首通 300；首次通关冒险 / 勇士 / 王者再得 200 / 300 / 500 | 一次性，按地下城 × 难度计 |
| 通关评价 | SSS 80、SS 60、S 40、A 20、B 10，C 以下 0；×（1 + 难度 × 0.25） | 每天上限 1000 |
| 每日任务 | 每完成一个每日任务 150，每天最多算 5 个（`CASH_EARN.dailyMax`） | 每日任务已有十几个（31~60 区域），点券每天最多 750 |
| 成就 | 见 1.2 | 一次性 |
| 金币兑换 | 50 金币 = 1 点券 | 每天最多兑换 500 点券 |
| 每日签到 | 由社交组发（登录后） | 不计入下面的模拟 |

## 2. 商城界面（`menus.open('cash')`）
- **入口**：
  - 菜单按钮栏“商城”，放在最下面一整行的金色按钮。
  - 快捷键 `]`：动作名 `cash`，可以在按键设置里改。
- **页签**：推荐 / 时装 / 武器装扮 / 天空 / 宠物 / 光环 / 消耗品 / 礼包 / 魔盒。
- **顶部**：
  - 三种货币的余额。
  - 按钮：点券获取、兑换商店、破晓启示（抽奖）、购买记录。
- **商品卡片**：
  - 图标、名字（按品级着色）、价格。
  - 角标：限购、折扣、热卖、新品、每周。
- **右侧详情**：
  - 预览：时装和天空套显示当前职业的试穿小人，宠物显示走动动画，光环显示脚下光效。
  - 说明、礼包内容清单、自选属性、数量、购买按钮。
- **限时特惠**（“推荐”页）：
  - 每日特惠 3 个，按日期轮换，7~5 折，每天限购。
  - 每周特惠 1 个，按周轮换。
  - 轮换由日期种子决定，所有玩家看到的一样。
- **购买记录**：保留最近 100 条（时间、商品、数量、花费）。
- **点券流水**：保留最近 50 条（时间、数额、来源）。

## 3. 时装（高级装扮）
3 套节日时装，三个职业都有整套帧集（外观组出图）。可以买单件，也可以买整套（整套 9 折）。

| 套装 | set | 主题 |
|---|---|---|
| 锦鲤贺岁 | `av_spring` | 春节：红金唐装、醒狮帽、长命锁 |
| 晴空海滩 | `av_summer` | 夏日：花衬衫、草帽、心形墨镜 |
| 星辉学院 | `av_academy` | 学院：藏青西装、格纹、贝雷帽 |

- 物品 key 是 `<部位>_<后缀>`，例如 `av_top_spring`。
- **换装规则**：同一套的上衣和下装都穿上，整个人换成这套；帽子、头部、脸部单独叠加。
- **出图**：外观组负责，五套时装（春节、夏日、学院、天空一、天空二）和六件武器装扮（金龙贺岁、清凉一夏、天穹圣翼、炎龙之魂、星辉学院、暗夜哥特，各 15 种武器类型）三个职业都已完成。帧集是 `spr/<职业>@<后缀>/`。
- **单件价格（点券）**：上衣 2600、下装 2200、鞋 1600、头部 1500、帽子 1500、脸部 1200、胸部 1200、腰带 1200。单件合计 13000，整套 11800。

### 3.1 自选属性（按官方装扮属性选择）
- 买到时是默认属性。第一次在“属性选择”里换是免费的，之后每次换要 1 张装扮属性变更券（`tk_avopt`，商城 100 点券）。
- 实例字段 `it.opt` 记录所选属性。商城组包装了 `applyDef`，按 opt 追加属性，旧存档和 normalize 都不受影响。

| 部位 | 可选（高级 / 稀有） |
|---|---|
| 头部、帽子 | 智力 6/10、精神 6/10、施放速度 2%/3%、力量 6/10 |
| 脸部、胸部 | 攻击速度 1.5%/2.5%、魔法防御 40/70、硬直 20/35、所有属性抗性 6/10 |
| 上衣 | 力量 8/14、智力 8/14、体力 8/14、精神 8/14（另有固定四维 +3/+5） |
| 下装 | HP 上限 200/340、MP 上限 160/270、物理防御 40/70 |
| 腰带 | 回避率 2%/3%、所有属性抗性 6/10、力量 6/10、体力 6/10 |
| 鞋 | 移动速度 4%/6%、力量 6/10、体力 6/10 |

- 帽子 / 头部多给了一项力量，是为了照顾物理职业。官方只有智力、精神、施放。
- **套装效果**：
  - 高级（每套各自计算）：3 件四维 +5；5 件攻击 / 施放速度 +1.5%；8 件伤害增加 +1%、移动速度 +2%。
  - 稀有（天空）：3 件四维 +10；5 件攻击 / 施放 / 移动速度 +2%；8 件伤害增加 +3%、暴击率 +1.5%，并激活身上光效。
- 数值按本作的属性尺度定（力量每点 +0.4% 攻击力，影响很大），经济模拟里一套节日时装约提升 11% 输出。

## 4. 天空套（稀有装扮）与合成

| 套装 | set | 主题 | 8 件套光效 |
|---|---|---|---|
| 天穹圣翼 | `av_sky1` | 白金天使、小羽翼、头顶光环 | 金色光粒和飘落的羽毛 |
| 炎龙之魂 | `av_sky2` | 黑红炎龙、小龙翼、龙角 | 上升的火星和暗红光 |

天空套不在商城直接出售。来源：合成、天空套部件兑换券（魔盒大奖、抽奖、兑换商店）。

**装扮合成器**（右键合成器，或在商城“天空”页点“装扮合成”打开）：

| 合成器 | key | 价格 | 投入 | 结果 |
|---|---|---|---|---|
| 装扮合成器 | `synth_basic` | 150 | 2 件同部位高级装扮 | 20% 得到指定天空套的该部位；失败得到 1 件随机的同部位高级装扮 |
| 黄金装扮合成器 | `synth_gold` | 600 | 同上 | 30% 成功，失败同上 |
| 梦想装扮合成器 | `synth_dream` | 1200 | 任意 8 件高级装扮 | 100% 得到指定部位的指定天空套 |

- 合成前选目标天空套（天穹圣翼 / 炎龙之魂）和成品属性。
- 成功时播放全屏演出（羽翼光柱），并发出全服公告 `bus.emit('announce', { kind: 'skyset', item })`。
- 成本估算（高级装扮按随机时装礼盒 900 点券 / 件）：
  - 普通合成器：每件天空期望约 5 次合成，净消耗约 6 件高级装扮 + 5 个合成器，约 6150 点券。
  - 黄金合成器：约 5900 点券，次数更少。
  - 梦想合成器：固定 8 件 + 1 个，约 8400 点券，胜在保底。
- 整套 8 件约 4.7 万点券，认真玩约 3 周，需要合成 25~40 次。

## 9. 经济模拟（`node test/shop_econ.mjs`，读真实数据）
模型：
- 疲劳 156 点 / 天，一次地下城约 7 个房间，约 20 次。
- 评价分布：认真玩家冒险难度（系数 1.25），SSS 15%、SS 35%、S 40%、A 10%；休闲玩家普通难度，S 30%、A 50%、B 20%。

| 玩家 | 每天 | 每周 |
|---|---|---|
| 满级认真玩家：20 次地下城 + 5 个每日任务 + 兑换 500 | 评价 1000（封顶）+ 任务 750 + 兑换 500 = 2250 | **15750**：节日时装整套 11800 约 0.7 周，节日礼包 15800 约 1 周 |
| 休闲玩家：每天 6 次地下城 + 2 个每日任务，不兑换 | 444 | 3108，约 4 周 1 套 |
| 新手第一周（Lv1→20） | — | 升级 8360 + 首通 5300（13 个地下城）+ 成就约 3590 + 日常 15750 ≈ **3.3 万**，开局很大方 |

- **成就**：由社交组的成就系统（149 个）统一发奖，其中包括商城原来的 14 个点券成就，不会重复发。
  - 第一周约 3590 点券。
  - 之后 6~8 周，每周另有约 3500，逐周减少。这部分只加快进度，不计入上面的稳态。
  - 公会商店每周最多换 3 个魔盒（社交组）。
- **天空套**：每件期望普通 6150 / 黄金 5900 / 梦想 8400 点券；整套 8 件约 4.7 万，认真玩约 3 周。
- **魔盒**：100 个 3 万点券，约 1.9 周，所以两周左右一定有一次大奖；平均每周 1~2 个大奖（主要是券和点券红包）。
- **对装备系统的影响**（和装备深化组一起把关）：
  - 计算方式：Lv20 鬼剑士，一身随机 Lv20 稀有装备和 +7 武器，用个人信息的 `gearMetrics` 算“输出”，逐步叠加商城物品。

    | 叠加 | 输出提升（累计） |
    |---|---|
    | 节日时装 8 件（选力量） | 约 11% |
    | 加礼包里的宠物、光环、称号、武器装扮 | 约 17% |
    | 时装换成天空 8 件 | 约 28% |
    | 满配：至尊称号 / 宠物 / 光环，神器宠物装备 | 约 48% |
    | 对照：只把武器换成同级史诗（+7） | 约 70~80% |

  - 结论：满配商城物品需要约 2 个月的认真产出，才抵得上一把史诗武器，装备仍是主体。
  - 魔盒出史诗 0.5%；史诗自选只给单件，不含深渊专属装备；装备强化券最高 +10，比官方魔盒弱。

## 10. 接口（给其他组）
- **点券**：`addCera(n, 来源)`、`spendCera(n, 原因)`、`cashBal('cera'|'shard'|'gcoin')`、`giveItem(makeItem('cera', n))`。
- **公告**：`bus.emit('announce', { kind: 'skyset', item })`、`bus.emit('announce', { kind: 'box', box, item })`。广播由社交组负责。
- **本组发出的事件**：
  - `cashBuy { pid, n, cost, cur }`
  - `boxOpen { key, items, jackpot }`
  - `skySynth { ok, item }`
  - `ceraGain { n, why }`
- **外观**：
  - `cashLook(equip)` → `{ pet, aura, sky8 }`
  - `cashAttach(ent, look)`：给联机组画其他玩家的宠物和光环（传 null 取消）
- **窗口名**：`cash`（商城）、`cashx`（兑换商店）、`lotto`（抽奖）、`synth`（装扮合成）、`pet`（宠物）、`boxopen`（开箱演出，阻挡操作）、`cashlog`（记录）、`ticket`（券的使用）。
- **快捷键**：`cash` = `]`。
- **测试**：`test/shop.mjs`（购买、合成、开箱、十连、多买多送、抽奖、兑换、宠物、光环、刷新）、`test/shop_econ.mjs`（点券产出模拟）。
