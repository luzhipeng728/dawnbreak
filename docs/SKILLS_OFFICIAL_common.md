# 官方对齐 · 操作与通用系统（三职业共用）

> 负责：神枪手对齐组。鬼剑士、魔法师的职业文档（`docs/SKILLS_OFFICIAL_sword.md`、`docs/SKILLS_OFFICIAL_mage.md`）引用本文，不重复写；神枪手见 `docs/SKILLS_OFFICIAL_gun.md`。
> 状态：Phase 1 调研 + 提案，**还没有改代码**，等用户拍板。
>
> 版本口径：
> - **经典** = 60/70 版本（2008–2014），本作最初按它做。
> - **现版** = 2016 技能窗口改版之后，直到 **千海天（2026-04）**。千海天是国服当前最新一次通用改动（官方页：dnf.qq.com/cp/a20260423job/）。
> - 两者不同时分开写；**默认建议跟现版**，除非特别说明。
>
> 置信度：**高** = 官方页面，或两个以上独立来源一致；**中** = 单一可靠来源，或推断；**低** = 来源弱或互相矛盾。

## 0. 结论（通用部分，按对手感的影响排序）

| # | 改动 | 为什么 | 置信度 |
|---|---|---|---|
| 1 | **删除 Shift / V「闪避翻滚」**，换成官方通用被动 **「后跳-强化」** | 官方 PC 版没有任何闪避 / 翻滚键。现在的八方向无敌翻滚是本作手感和官方差得最多的一项 | 高 |
| 2 | **技能 → 技能 不再能随便互相取消**，改成白名单：①固定衔接 ②职业专属机制（如女漫游「花式枪术」有次数）③后跳-强化 | 官方没有通用的技能互相取消。本作任何技能过了 `cancelFrom` 都能接任何技能，太"软" | 高 |
| 3 | **受身蹲伏**改成"倒地后按 C 蹲伏无敌，按住最长 3 s，松开起身 + 0.3 s 霸体，冷却 5 s" | 本作是"快落地就能按、立刻起身、冷却 2.5 s" | 高 |
| 4 | **Z 与 Space 分开**：Z 类指令只认 Z，Space 类（多为 Buff）只认 Space | 本作 Space 兼任 Z，方向 + Space 也能放出 Z 类技能 | 中 |
| 5 | **技能等级上限跟角色等级挂钩**（`lvStep`）、**每级 SP 固定**、补**前置技能** `pre` | 本作学习等级一到就能点满，每级 SP 递增，没有前置 | 高 |
| 6 | **技能栏 14 格**（ASDFGH + 左 Alt、QWERTY + 左 Ctrl） | 本作 12 格 | 高 |
| 7 | **统一等级压缩表**（第 7 节），为一觉 / 二觉 / 三觉 留出等级 | 本作上限 30 级，现有压缩只覆盖到官方 45 级 | — |
| 8 | **转职窗口支持 5 个选项**，每个转职有自己的转职任务线 | 官方三个职业现在都是 5 个转职 | 高 |
| 9 | **指令施放不再减 MP / 冷却** | 千海天（2026-04）删除了这个奖励；本作是所有技能 ×0.98 / ×0.99 | 高 |
| 10 | 补通用技能：**跃翔**、**基础精通**；**召唤物框架**（魔法师组主提） | 缺 | 高 |

## 2. 通用动作

### 2.1 普攻（X）框架
| 项目 | 官方 | 本作现状 | 建议 | 置信度 |
|---|---|---|---|---|
| 连段 | 连按 X，段数随职业和**武器类型**变化；最后一段击退 / 击倒更强 | 各职业 `acts.atk1..N` + `chain` 窗口 | 保留 | 高 |
| 按住 X | 经典要连按；2016 起有预输入；现版快捷键设置里有「普通攻击连发」勾选项 | `hold: true` 时按住 X 自动接下一段 | 保留为默认，加一个设置项"按住 X 连发"（界面组） | 中 |
| 武器类型差异 | 同一职业换武器，普攻段数、速度、射程、硬直、判定都会变（例：神枪手 左轮 4 发 / 自动 6 / 步枪 3 / 手炮 2 / 手弩 7；鬼剑士 太刀快、巨剑慢范围大、钝器几率眩晕、光剑感电） | 只有神枪手按武器改发数 | **引擎钩子**：`WEAPON_FEEL[cls][wtype] = { n, aspd, range, stun, knock, pierce, ... }`，普攻动作读它缩放。各职业的具体数值写在自己的文档里 | 高 |
| 被动改写连段 | 例：剑魂「里·鬼剑术」多出第 4 / 5 段（段数随武器变化） | 剑魂已经用 `next: p => skLv(...)` 做了 | 保留这种写法，作为通用约定 | 高 |
| 普攻 → 技能（强制） | 经典要学「强制-XX」；现版大部分攻击技能自带"普攻中可取消"。**Buff 类技能不能取消普攻**（例：空中射击、银弹写明"无法强制中断普通攻击"） | 普攻随时能被任何技能取消 | 加 `S.noForce`（Buff 默认 true）：普攻中按这类技能无效，缓冲到普攻结束 | 高 |
| 普攻 → 后跳 | 可以（70 版要学「强制-后跳」，现版自带） | 普攻命中判定之后才能后跳 | 改成普攻任何时候都能后跳 | 高 |

## 5. 取消规则（最影响"像不像官方"）

### 5.1 官方规则
| 从 → 到 | 官方 | 本作现状 | 置信度 |
|---|---|---|---|
| 普攻 → 攻击技能 | 可以（强制） | 可以 | 高 |
| 普攻 → Buff 技能 | **不可以** | 可以 | 高 |
| 普攻 → 后跳 | 可以 | 命中后才可以 | 高 |
| 技能 → 其他技能 | **默认不可以**。只有：①固定衔接（例：女枪 滑铲 → 浮空铲 / 钉刺射 / 上旋踢；上旋踢 → 刺踢 / 浮空弹）②职业专属机制（女漫游「花式枪术」有次数、剑魂「流心」、剑影「鬼步」、战斗法师「尼巫的战术」命中后取消……）③后跳-强化 | `cancelFrom` 之后可以接**任何**技能 | 高 |
| 技能 → 后跳 | 只有后跳-强化（冷却 40 s） | `cancelFrom` 之后可以 | 高 |
| 觉醒 | 不能被取消，也不能被后跳-强化取消 | 觉醒没有 `cancelFrom`，一致 | 高 |
| 同一技能的追加段 | 再按技能键（三段斩、双鹰回旋、锁链截击第 2 / 3 击…） | `follow` / `followWin` | 高 |

### 5.2 引擎实现（`src/game/player.js`，第 1 阶段已实现；字段不存在时就是原来的行为）

**取消**
- `canCancelInto(p, id)`：当前动作能否被技能 `id` 打断。
  - 普攻（含跑攻、跳攻）→ 任何攻击技能；`S.noForce`（Buff 默认 true）的技能不能强制中断普攻，按键留在缓冲里，普攻结束后放出。
  - 后跳中 → 只有 `S.air` 的技能（后跳算空中）。
  - 技能 → 其他技能：只有白名单。
    - `links: [技能id…]`（写在动作上或 `SKILLS[id]` 上）。
    - `linkFrom: 秒`（从第几秒开始认 links，默认 0）。
    - `hitCancel: true`（本技能命中后 links 才开放：`act.hitAny || p.hitsDone.size > 0`；投射物类技能在 onHit 里自己写 `e.act.hitAny = true`）。
    - `CLASSES[cls].cancelHook(p, act, id)`：职业专属柔化（女漫游「花式枪术」这类次数制），返回 true 就放行。
  - 觉醒：不能被取消，也不能被后跳-强化取消。
  - 旧字段 `cancelFrom` 只剩两个用途：`cancelable: true` 的模式类动作（移动射击等），以及后跳-强化最早能用的时机（统一 0.05 秒）。
- `canSkillCancel(p)` 保留给 AI 判断“忙不忙”。

**派生键**
- 动作上的 `keyLinks: { attack | cmd | cmdB | jump: 技能id }`：动作中按这个键就放出这个技能（例：女枪滑铲中按 X = 上旋踢）。`linkFrom` 同样生效。
- 倒地 / 起身中：`CLASSES[cls].getupLinks`（例：女枪倒地时按 X = 起身上旋踢；放出时给 0.15 秒无敌）。
- 待命状态（流心等）继续用动作的 `onInput` 自己分派（剑士文档）。

**技能字段钩子**
| 字段 | 作用 | 谁要用 |
|---|---|---|
| `S.req(p)` → `true` 或失败提示 | 施放前置条件；快捷栏、指令、AI 都走它；指令冲突时不满足的技能不占用指令 | 剑士（狂暴之力中、卡洛中、无尽波动中、HP ≤ 50%…） |
| `S.morph(p)` → 替代技能 id | 某状态下同一个键放另一个技能（替代技能没学时用原技能的等级） | 剑士（暗天波动眼） |
| `S.whenHit` = `true` 或函数 | 受击硬直 / 倒地中才能放（函数可自定，例如浮空也行）；被抓、冰冻、眩晕时不行。受击 / 倒地 / 浮空状态下只扫描这些技能 | 魔法师 替身草人、剑士 幻鬼步、女漫游 心灵反击 |
| `S.airIf(p)` | 满足时可以在空中放 | 魔法师（空中施放：杰克爆弹） |
| `S.recast = { ok(p), act(lv, p), cd, mp }` | 召唤物 / 放置物在场时再按技能键（在冷却检查之前；内部冷却 `p.cool[id + '~']`）；技能栏画绿框 | 魔法师、机械师、弹药专家 |
| `S.instant(lv, p, extra)` | 无动作施放：不调用 `doAct`、不打断当前动作、不走取消规则 | 协战师、剑影、鬼泣 |
| `S.only` / `S.excl` + `skillAllowed(id, job)` | 基础技能的转职限制（没转职时都能学）；classSkills、hasSkill、技能窗口、castSkill 都已接上 | 全部（例：EZ-8 只有机械师） |
| `S.charges`、`S.reload` | 装填次数制（`p.charges[id] = { n, t }`；快捷栏显示 ×n） | 女枪 G-14、弹药专家手雷 |
| `S.noWtype: [武器类型…]` | 这些武器不能用 | 女枪 烟尘弹（手炮不能用） |
| `CLASSES[cls].onHurt(p, 攻击者, h, dmg)` | 受击后（makePlayer 里接好了 `p.onHurt`，同时记 `p.hurtT`） | 剑士（挫折意志等） |
| `CLASSES[cls].airMaxOf(p)` | 每次跳跃的空中攻击上限 | 女枪（按武器 + 空中射击） |
- 受击前钩子（beforeHurt：减伤 / 格挡 / 不硬直）在 `engine/combat.js`，由魔法师组负责（主线程分配）。
- 注意：技能 → 技能的默认互取消已经全部关掉，各职业需要的衔接都要写成 `links`（剑士 7 项、魔法师见各自文档；神枪手见 gun 文档第 3.2 节）。AI 的连招改成“普攻起手接技能”。

## 7. 等级压缩表（三职业统一）

本作 `MAX_LVL = 30`，官方现在 110 级（一觉 50、二觉 75 / 85、三觉 100）。旧的压缩规则（官方 15→15、20→17 … 45→27，觉醒统一 18）只覆盖到官方 45 级，放不下一觉之后的技能。

**建议公式**：官方学习等级 ≤ 15 → 不变；> 15 → `本作 = round(15 + (官方 − 15) × 15 / 85)`。

| 官方 | 15 | 20 | 25 | 30 | 35 | 40 | 45 | 48 | **50 一觉** | 55 | 60 | 65 | 70 | **75 二觉任务** | 80 | **85 二觉技能** | 90 | 95 | **100 三觉** |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 本作 | 15 | 16 | 17 | 18 | 19 | 19 | 20 | 21 | **21** | 22 | 23 | 24 | 25 | **26** | 26 | **27** | 28 | 29 | **30** |

- 转职等级保持 15（官方 17 / 18，不变）。
- 一觉任务 18 → **21**，二觉任务 **26**，三觉任务 **30**（= 满级）。需要主线程和任务组同意。
- 官方 105 / 110 级的技能（如果有）不做。
- **备选**：保持一觉 18 不动 → 官方 15–50 压到 15–18，50–100 压到 18–30。缺点是转职技能在 15–18 三级里全部解锁。
- **另一个备选**：提高 `MAX_LVL`。这需要新地下城和经验曲线，不在本次范围。

## 9. 召唤物框架（魔法师组主提，完整设计见 `docs/SKILLS_OFFICIAL_mage.md` 第 6 节）

本作现状：召唤物用 `spawnProj` 模拟，不能被打、没有 HP；换房间时 `src/game/dungeon.js` 第 75 行 `projs.length = 0` 会清掉。官方的 G 系列、狂风、召唤兽会跟着进下一个房间。

框架 v1 要点（魔法师组）：
- 新文件 `src/game/summon.js`（ORDER 里放在 `engine/proj.js` 之后）。
- `defSummon(key, {...})`，三种 kind：`follower`（伙伴实体，进 `ents`）、`field`（定点区域）、`attach`（挂在实体身上）。字段 `max` / `tagMax`（数量上限）、`over`（到上限时 oldest / refresh / deny）、`life`、`keepRoom`（跨房间）、`cmds`、`hp`（省略 = 打不到）。
- 调用：`summon(owner, key, o)`、`summonsOf(owner, key | {tag})`、`summonCmd(...)`、`dismissSummons(...)`；全体开关读 `owner.summonMode`。
- 伤害按主人面板实时结算；联机时 `net/coop.js` 已认 `a.owner === game.player`。
- **再按技能键**：`castSkill` 在冷却检查之前加 `S.recast = { ok(p), act(lv, p), cd, mp }`；技能栏"可再按"时画绿框（界面组 hud.js）。
- AI：技能写 `ai.summon = key`，到上限就不再放，有 `recast` 就改用 recast。

三个职业的需求汇总：
- 寿命、自动索敌（最近 / 最强）、攻击节奏、到时自爆 / 消失。
- 按类型的**数量上限**（超出时挤掉最旧的）：例 Ex-S 最多 9、G-2 三台、G-3 六台、拦截机六架。
- 跟随主人（偏移位置），**跨房间携带**。
- 按主人和类型查询（机械引爆、G 系列改装、召唤兽跟随 / 解除）。
- **再按技能键**钩子：在冷却 / MP 检查之前拦截（G-2 发射、G-3 附着 / 按住回收、C4 / 地雷引爆、召唤兽指令）。
- 开关型指令（机械指令、狂风自爆、召唤兽跟随 / 召唤解除）。
- 可选（P2）：有 HP、能被怪物打的召唤物（拦截机工厂）。
- 神枪手要用的：基础技能 RX-78 追击者；机械师全套；弹药专家的 M18 / C4（放置物 / 附着物，可以共用"再按引爆"钩子）。

## 10. 手感数值框架（引擎约定）

官方没有公开逐招的硬直 / 击退帧数，只有相对关系（例：神枪手普攻硬直 手炮 > 步枪 > 左轮 > 手弩 > 自动）。本作沿用现有字段，约定：
- `stun`（硬直秒数）、`knock`（击退速度）、`hs`（hitstop）、`launch` / `airLift`（浮空）、`down`（倒地）照旧；**武器差异用倍率**，由 `WEAPON_FEEL` 统一乘，不在每个技能里写死。
- 普攻"最后一段"统一：`knock` 更大、`hs` +0.02。
- 霸体（`superArmor`）、无敌（`invul`）按官方描述逐技能标注（各职业文档里写"起手霸体 / 全程霸体 / 无敌"）。
- 性能规范不变：每帧绘制不用 `filter`、`shadowBlur`，混合模式只用 `source-over` / `lighter`。
