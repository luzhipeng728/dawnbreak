# 官方对齐 · 神枪手（女）

> 用户反馈："好多技能和官方的不一致，操作不习惯"；"技能本身不对、普攻手感不对"；"技能得加全了"。
> 本文：官方 **神枪手（女）** 完整技能树（基础 + 全部 5 个转职，到三觉）与本作逐项对照，加上优先级改动清单、美术需求、存档迁移。
> 操作、取消规则、技能系统形式、等级压缩这些**三职业共用**的内容写在 `docs/SKILLS_OFFICIAL_common.md`，本文只写神枪手特有的部分。
> 状态：Phase 1 调研 + 提案，**还没有改代码**，等用户拍板。
>
> 版本口径：**经典** = 60/70 版本（2011–2016）；**现版** = 到千海天（2026-04）为止的国服。默认跟现版，除非特别说明。
> 置信度：**高** = 官方页面，或两个以上独立来源一致；**中** = 单一可靠来源；**低** = 来源弱或冲突。
> 等级：`官方Lv→本作Lv` 按 common.md 第 7 节的统一公式换算：官方 ≤15 不变，否则 `round(15 + (官方 − 15) × 15/85)`。常用值：20→16、25→17、30→18、35→19、40→19、45→20、48/50→21、60→23、70→25、75/80→26、85→27、95→29、100→30。

## 0. 结论

### 0.1 用户的抱怨对应到哪里
| 抱怨 | 主要原因 | 见 |
|---|---|---|
| 操作不习惯 | 本作有官方没有的 Shift/V 无敌翻滚；技能之间能随便互相取消；Space 兼任 Z；受身蹲伏立刻起身 | common.md 第 1、2、5 节 |
| 普攻手感不对 | 没有拔枪前摇和收枪 / 装填后摇（"太连"）；多了官方没有的 ↑X 上射；5 种武器只有发数不同，射程、硬直、穿刺一样，手炮也打子弹；每次跳跃固定 8 发，等于"空中射击"常开 | 第 2 节 |
| 技能不对 | 基础技能名字和指令基本对，但 银弹 / G-14 / 浮空铲 机制不同；**漫游基本是男漫游换了女模型**（没有枪刃、锁链、花式枪术，一觉也是男版结构）；枪炮师缺整套重火器被动，激光炮等机制有出入 | 第 3、4、5 节 |
| 技能不全 | 基础缺 RX-78、空中射击、烟尘弹、起身上旋踢；官方现在有 **5 个转职**（漫游 / 枪炮师 / 机械师 / 弹药专家 / 协战师），本作只有 2 个；两个已有转职都只做到官方 45 级 + 一觉 | 第 3–8 节 |

| 部分 | 官方技能数（到三觉） | 本作现有 | 本作可覆盖（30 级内） | 代码工作量 | 美术 |

"×7 套"：新人物动作帧除了基础 `gun`，还要给 6 套时装帧集（`gun@academy / festival / sky1 / sky2 / spring / summer`）各出一遍（外观流水线 `avatar_gen.py wpn` → `avatar_frames.py`）。协战师在地下城里穿战斗服、不显示时装，所以不用乘 7。

### 0.3 推荐的前 10 项改动（按顺序）
1. 删 Shift/V 闪避 → 官方「后跳-强化」；受身蹲伏改成官方（蹲伏无敌、按住延长、冷却 5 s）。（common）
2. 技能互相取消改成白名单：滑铲 → 浮空铲 / 钉刺射 / 上旋踢，起身上旋踢；漫游用"花式枪术"次数制柔化。（common + 第 3.3 节）
3. 普攻重做：拔枪前摇 + 收枪 / 装填后摇，按武器区分射程 / 硬直 / 穿刺，手炮改成近距离范围判定，去掉 ↑X，跳射按武器定上限，补"空中射击"。（第 2 节）
4. 键位：Z / Space 分开，技能栏 14 格，删掉指令减 MP / 冷却。（common）
5. 技能等级随角色等级（`lvStep`）、每级 SP 固定、补前置技能。（common + 各表"前置"列）
6. 基础技能修正与补齐：RX-78、空中射击、烟尘弹、起身上旋踢；浮空铲改主动；银弹按发数；G-14 三颗装填；M-137、BBQ、上旋踢数值。（第 3 节）
7. 漫游重做成女版：双枪极舞刃（4 个派生）、花式枪术、锁链截击、心灵反击、致命回射、音速劫击、远程格挡；一觉改成「绯红盛宴」。（第 4 节）
8. 枪炮师补重火器系统（精通 / 拔击 / 奥义）、蓄电激光炮、潜能爆发、FM-92 mk2；修 激光炮 / 加农炮（千海天改 ↓+Z）/ 反坦克炮 等。（第 5 节）
9. 新等级表（一觉 21、二觉 26/27、三觉 30），两个已有转职补到三觉；做一次 v5 洗点迁移。（common 第 7、11 节 + 第 12 节）
10. 新转职：机械师、弹药专家（协战师建议缓做）；转职窗口支持 5 个选项，每个转职一条官方转职任务线。（第 6–9 节）

## 2. 普攻与基础动作（P0）

### 2.1 官方 vs 本作
| 项目 | 官方 | 本作现状 | 差异 | 置信度 |
|---|---|---|---|---|
| 地面一轮发数 | 左轮 4、自动手枪 6、步枪（火枪）3、手炮 2、手弩 7 | 相同 | 一致 | 高 |
| 拔枪前摇 | 按 X 先拔枪，速度：自动 > 左轮 > 手弩 > 步枪 > 手炮 | 没有 | 缺 | 中 |
| 最后一发 | 最后一发击退更强（女枪台词 Catch! / Finally） | 最后一发 knock 160、lift 220 | 一致 | 高 |
| 收枪 / 装填 | 打完一轮要收枪 / 装填（漫游「左轮奥义」「快速拔枪」缩短） | 没有，打完立刻能开下一轮 | 缺；这是"太连"的主要原因 | 中 |
| 按住 X | 经典要连按；现版有「普通攻击连发」设置 | 按住就自动连射 | 保留，做成设置项（common 2.1） | 中 |
| 平射 / ↓X | 平射；↓X 打地面，能打到倒地的敌人（"拖地"：↓X 打倒地的敌人，再强制接钉刺射 / BBQ 拉起来） | ↓ = 低射，能打倒地 | 一致 | 高 |
| ↑X | **普攻没有向上斜射**（能调上下方向的是格林机枪；浮空弹能平射 / 下射） | ↑ = 斜上射，托住空中的敌人 | **本作独有，建议去掉** | 中 |
| 武器差异 | 硬直：手炮 > 步枪 > 左轮 > 手弩 > 自动。射程：步枪 > 左轮 > 手弩 > 自动 > 手炮。穿刺：手炮 100% > 步枪 > 左轮 > 自动 > 手弩。**手炮普攻不是子弹，是前方一小块范围判定（能穿障碍）**，空中命中直接打倒地 | 各武器只有发数不同；射程（life 0.52）、硬直（0.22）一样；手炮也打子弹 | 缺 | 高 |
| 跳射 | 空中按 X 斜向下射击；空中没有"最后一发"；**每次跳跃有发射上限**（手炮基础 1 发，其余基础值没有官方写明）；后坐力看武器：手炮向后飘、步枪向上、手弩下坠、自动几乎停在空中 | 每跳 8 发，重力 0.55，没有武器差异 | 8 发 ≈ "空中射击"常开 | 高（基础上限除手炮外：低） |
| 空中射击（Buff） | Lv15，↑↑+Space，冷却 40 s，持续 25 s：跳射攻击力、发数上限、滞空增加。额外发数 1 级 / 10 级：左轮 +4 / +8，自动 +6 / +12，步枪 +3 / +7，手炮 +2 / +4，手弩 +7（现版 +5）/ +14。女弹药转职时自动学会，学了单兵推进器后常驻 | 没有 | 缺 | 高 |
| 跑攻（滑铲） | X 轴位移很长；可以强制中断滑铲接 浮空铲 / 上旋踢 / 钉刺射；另有"短滑铲"技巧 →→↓X / →→↑X | 滑铲；学了被动 g_slide 后所有滑铲都挑空 | 浮空铲应是主动技（见 3.1） | 高 |
| 后跳中射击 | 官方**没有**通用的"后跳射击"；后跳算空中，可以接空中类技能 | 没有 | 不需要做 | 中 |
| 女枪 vs 男枪 | 女枪多数动作单手持枪（男枪双枪）；移速、攻速更快，单发低、段数多；**后撩踢按住 → 会向前滑半个身位** | 职业描述写"手持双左轮" | 描述改；后撩踢补前滑 | 中 |

**概况**（高）：国服 2025-06-12 上线（韩服 Paramedic），神枪手（女）第 5 转职，**辅助（奶）职业**，物理**独立攻击**、主属性精神、左轮。觉醒：一觉 **督战官** → 二觉 **战勤统帅** → 三觉 **重霄·协战师**。**没有转职任务**（官方是创建角色时直接选；导师凯丽）。**进地下城自动穿"强袭战斗服"变身**，所有动作换成战斗服近战体系 [SCQC]，地下城里不显示时装。

**核心机制**：
1. **战场信息层数**：普攻命中 +5%、技能命中 +10~40%，满 100% 得 1 层，最多 3 层；Buff / 模件技能消耗层数。
2. **无动作施放**：Buff 类可以在任何动作（包括技能、觉醒）中直接放出，不打断当前动作（common 5.2 `S.instant`）。
3. **同步**：所有 Buff 全队生效，不看距离、跨房间。
4. **保护罩**：可叠加的吸伤护盾（上限最大 HP 的 50%+），**没有治疗技能**；"强化保护罩"= 减伤 20% + 霸体。
