建议职业扩展：`ff: { buffs: [{id,src,targets,expires,stacks}], shield: [...], revive: [...] }`。字段名称待实现时遵循现有 `p/a/hb` 协议，不在本研究稿中锁死。

蓝拳的关键是动作状态而非面板 BUFF：同步 `willDriver` 是否存在、区域位置/半径/结束时间、`ducking/sway` 当前状态、柔化窗口、反击祈祷窗口、分身列表和飓风实体。主机裁决反击是否命中、飓风吸附和目标硬直；影子只按 `skill id + action phase` 重放拳影。不要把俯冲/摆动当普通位移，否则远端会出现连招不同步。

建议职业扩展：`ff: { will: {x,y,r,expires}, motion: 'duck'|'sway'|null, counter: {armed,expires}, clones: [...], hurricane: [...] }`。

建议职业扩展：`ff: { gauge, gaugeMax, half: {on,expires}, demon: {on,expires}, barrier, skillMorph }`。不要在客户端自行递减能量后再把结果发给主机，避免高延迟下半魔化时间分叉。
