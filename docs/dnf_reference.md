# DNF 玩法复刻参考（Dawnbreak 设计用）

> 目标：用于"玩法手感"复刻。名称、剧情、美术、音乐须原创，本文只描述机制与表现。
> 基准版本：以国服 60/70 级经典期（2008–2014，"大转移"前）为主，涉及现版本数据时注明。
> 标注：【不确定】= 资料冲突或未查证；【建议】= 本文给出的实现取值，不是 DNF 原数据。

---

## 1. 操作

### 1.1 默认键位
| 功能 | 默认键 | 备注 |
|---|---|---|
| 移动 | ↑↓←→ | ↑↓ 在纵深方向移动（2.5D） |
| 跑步 | 快速双击 ←/→ | 松开方向键即停止跑步 |
| 普通攻击 | X | 同时兼作拾取、确认（旧版死亡时按 X 用复活币） |
| 跳跃 | C | 空中按 X 为跳跃攻击 |
| 指令键 | Z、Space | 方向 + Z/Space 用指令放技能；Z/Space 本身也可放一个技能 |
| 技能栏 1 行 | A S D F G H（+ 左 Alt） | 现版本 7 格 |
| 技能栏 2 行 | Q W E R T Y（+ 左 Ctrl） | 60 版本扩展栏为 F1–F6 |
| 消耗品栏 | 1–6 | 药剂、投掷物 |
| 宠物技能 | V | |
| 界面 | I 物品、K 技能、M 个人信息/状态、Q 任务、U 装扮、O 设置、Esc 系统菜单 | M 是**状态窗口**，不是地图。公测资料写 **N 为地图**，现版本对应键【不确定】 |
| 杂项 | Tab 切换 UI 显示方式；Ctrl 显示/隐藏地面掉落物名称；R 切换技能/装备说明详略；End 隐藏右下角评分 | |
| 复活队友 | F1–F4（另一资料为 F9–F12） | 用自己的复活币 |

### 1.2 动作与指令
- **普攻连段**：连按 X，段数取决于职业和武器。神枪手每轮连射数：火枪 3、手炮 2、自动手枪 6、左轮 4、手弩 7。鬼剑士约 3 段，末段击退【不确定】。
- **前冲攻击**：跑动中按 X。鬼剑士跑攻后再按 X 接"连突刺"，神枪手跑攻是滑铲。
- **跳跃攻击**：空中按 X，可以连续出招。剑魂有"空中连斩"，神枪手有"空中射击"（空中停留更久）。
- **后跳**：按住 ↓ + C，耗 1 MP，瞬发，向后小跳躲攻击，常用来取消后摇。起跳段带短暂无敌，时长【不确定】，【建议】约 0.2 s。
- **受身蹲伏**：倒地时按 C，立刻起身并进入蹲伏。蹲伏期间无敌，起身时有 0.3 s 霸体，冷却 5 s，耗 1 MP。无敌时长：技能说明写 3 s，另有资料说 1 级约 1 s、满级约 3 s，按住按键可以延长。
- **指令技能**：例如 ↓→+Z。在技能窗口右键点技能图标可以锁定指令，锁定后只能用快捷栏释放。现版本用指令释放有 MP −2%、冷却 −1% 的奖励。
- **强制（取消）**：早期要学"强制-XX"才能在普攻中途打断并接技能；现版本基本所有技能都能取消普攻。这是连招手感的核心。

## 2. 战斗机制

### 2.1 伤害公式（可以直接实现）
- 百分比技能伤害 ≈ 技能% × 武器攻击 × (1 + 力量×0.004) × (1 − 防御减伤) × [1 + (属性强化 − 抗性)/220] × 暴击倍率 × 破招倍率。魔法职业把力量换成智力。
- **暴击**：×1.5。物理暴击率和魔法暴击率分开计算。
- **破招 COUNTER**：命中处于攻击或施法动作中的敌人，伤害 ×1.25，屏幕弹出"Counter"。
- **背击 BACK ATTACK**：从背后命中，弹出"Back Attack!!"。伤害公式里没有背击倍率（本身是否加伤害【不确定】），被动技能"物理背击/魔法背击"可以提高背击时的暴击率。
- **Over Kill（额外伤害）**：击杀的那一击超过目标最大 HP 的 30%。

### 2.2 受击状态
| 机制 | 规则 | 【建议】实现 |
|---|---|---|
| 硬直 | 硬直时间由攻击方的"硬直强度"减去受击方的"硬直"属性决定，硬直期间输入无效 | 普攻约 0.25 s，重击 0.5–0.8 s |
| 霸体 | 角色全身轮廓发红光；不会硬直、倒地、浮空，但照常受伤。上挑、膝撞、上勾拳、空斩打等起手技在释放瞬间带霸体 | 用红色描边 shader 表现 |
| 浮空 | 技能有"浮空力"。敌人被打上天后，空中命中计为 Aerial（凌空追击）。怪物有"重量"，影响下落速度 | 重力加速度 + 每次空中受击向上补一点速度 |
| 浮空保护 | 决斗场规则：从站立被打浮空起累计受到 20% 最大 HP 伤害后加速下落，之后每多 5% 再加重一次；非倒地、非浮空的可行动状态持续 3 s 后清零。PvE 怪物的具体规则【不确定】 | PvE 也做一个"浮空次数衰减"：第 N 次被挑空时浮空力 ×0.85^N |
| 倒地 | 多数技能的最后一击使目标倒地；倒地后仍能被"扫地"技能（如下段踢）命中。决斗场里倒地后累计受到 20% 伤害会强制起身，并有 0.7 s 无敌 | 起身无敌 0.5–0.7 s |
| 抓取 | 裂波斩上斩、背摔、踏射、BBQ、虎袭、嗜魂之手等技能锁定单个目标，可以抓住霸体和格挡中的敌人；部分大体型敌人不可抓 | 被抓取期间目标完全不能行动 |
| "建筑"类怪物 | 不能浮空、不能倒地、不能位移 | 用于塔、柱子、召唤物 |
| 击退 | 普攻末段和地裂·波动剑会水平推开目标 | 沿水平方向给一个冲量 |
| 打击停顿 | 具体帧数【不确定】；设置里有"画面晃动特效"开关，说明屏幕震动确实存在 | 【建议】普攻 50–70 ms，重击 100–150 ms，觉醒 200 ms 以上并叠加屏震 |

### 2.3 属性与异常状态
- 属性分火、冰、光、暗，以及无属性。每种属性有强化和抗性两个数值。

| 状态 | 表现 | 效果 |
|---|---|---|
| 中毒 | 身上冒紫光，HP 条变紫 | 持续扣固定 HP |
| 灼伤 | 身上冒烟冒火 | 持续火属性伤害，会波及周围单位 |
| 感电 | 身上闪电光 | 每次被击中附加光属性伤害 |
| 出血 | 持续溅血 | 持续扣 HP，资料称期间受到的伤害提高到 1.5 倍【不确定】 |
| 冰冻 | 全身被冰块包住 | 不能行动，受到火属性攻击立即解冻 |
| 石化 | 下半身变成石头 | 不能移动、不能攻击 |
| 眩晕 | 头顶转星星 | 不能移动、不能攻击 |
| 失明 | 头顶黑光，屏幕变黑 | 只能看见角色周围约一个身位的范围 |
| 睡眠 / 混乱 / 束缚 | 睡眠：受到攻击即醒；混乱：方向键左右上下反转；束缚：不能移动但可以攻击 | |
| 减速 / 诅咒 | 减速：脚下有漩涡；诅咒：身上有黑光 | 减速降低移动和攻击速度；诅咒降低全部属性 |

- 伤害数字颜色：主伤害为**大号黄字**；附加伤害为小号黄字（老版本是白字，所以玩家叫它"白字"）；**暴击为红字**；**异常状态伤害为蓝字**；回复为绿字；队友造成的伤害为灰字。

### 2.4 连击、MP 与觉醒
- **连击数**显示在画面右上方，形如"N Hit Combo!"：10 连以上数字变黄，20 连以上变红。每打出一次 5 连以上的连击就计一次操作分。
- 技能消耗 MP，普攻不消耗；MP 会随时间自动恢复。技能图标按冷却进度转圈变暗。
- **觉醒**（Lv50 一觉，75 二觉，100 三觉）：释放时画面变暗并弹出角色立绘插图（设置里有"技能插图特效"开关），伴随专属台词，冷却很长【约 140–180 s，不确定】。不同技能保护不同，例如剑圣的觉醒在剑阵展开后全程无敌，元素师的"陨星幻灭"只有霸体没有无敌。

## 3. 画面与界面

### 3.1 场景构成
- 原始分辨率 800×600（4:3），后来加入 16:9 等宽屏（例如 1067×600）。
- **2.5D 横版**：背景分多层做视差滚动；下方是一条可以走动的地面带，角色能在纵深方向上下移动，脚下有椭圆阴影。
- 比例【估算，不确定】：地面带约占屏高 30%；人物约占屏高 18–22%（600 像素高的屏幕上约 110–130 像素）；一个房间宽 1–3 屏，镜头跟随角色横向卷动。

### 3.2 HUD
- **底部**：HP（红）和 MP（蓝）是"血球/蓝球"，分在技能栏两侧【样式随版本有变化】；中间是两排技能栏，图标上显示冷却和对应按键；下方是横条经验条和横条疲劳条；消耗品栏 1–6；另有 SP 数值和 BUFF 图标。
- **右上**：地下城名称、难度和小地图。
- **右下**：实时评价，显示操作、技巧、被击数和当前评级字母，按 End 可隐藏。
- **目标血条**：攻击某个怪时，屏幕上方显示它的头像、名字、等级和血条。普通小怪头顶不显示血条，精英怪头顶有。**领主（BOSS）血条分多管**，每管颜色按紫→蓝→绿→黄→红循环，旁边显示剩余管数"×N"。
- **弹出文字**：Counter、Back Attack!!、Aerial、Over Kill、Double Attack（组队时两人同时打中同一个怪）、Critical、Miss。

### 3.3 小地图与房间
- 房间用方格表示，方格之间的连线表示门。当前房间高亮；领主房有专门的图标【具体样式不确定，建议用红色骷髅】；深渊房、特殊房用紫色；未探索的房间显示为暗色。
- 清空房间内所有怪物后，门开启并发光，同时有音效；走进门即切换到下一个房间。
- 击杀领主后通关。击杀瞬间的慢动作或白闪【不确定，建议加上】。

### 3.4 结算与城镇
- **结算界面**：通关时间、评级字母（F→SSS）、操作/技巧/被击数分项、经验明细（击杀+通关+评价加成）→ 翻牌 → 继续捡掉落 → 再次挑战或返回城镇。
- **城镇**：同为 2.5D 横版，NPC 头顶显示名字（如"铁匠 XX"）；地图边缘是出口，走进"地下城入口"区域弹出地下城选择界面。

## 4. 地下城流程

1. 城镇 → 走到区域入口 → 打开选择界面（地下城列表、推荐等级、难度按钮）→ 进入。
2. **难度与解锁**（经典期）：

| 难度 | 解锁条件 | 经验倍率 |
|---|---|---|
| 普通 | 无 | 1.0 |
| 冒险 | 通关普通 | 约 1.3–1.4 |
| 勇士 | 冒险难度评价 B 以上 | 约 1.8 |
| 王者 | 勇士难度评价 S 以上 | 约 2.2 |

- 2009 年论坛给出冒险/勇士/王者分别为普通的 1.4/1.8/2.2 倍；较新的资料说相邻两档之间约 1:1.3。
- 后期版本增加了"地狱"和"噩梦"：噩梦要求王者难度 SSS 评价、不用复活币、被击数少于 5 次。
- 高难度下怪物 HP 和攻击力更高、更常开霸体、更会闪躲；具体倍率【不确定】，【建议】每档 HP ×1.6、攻击 ×1.3。有资料称高难度并不提高掉率【不确定】。
- 难度由队长决定，队长已解锁即可带全队进入。
3. **房间与路线**：从起点出发，可以直达领主房，也可以清完全图，全图掉落和经验更多。有些地下城有隐藏房或深渊房，出现"绿名怪"时必须清掉。
4. **疲劳值**：每天 06:00 重置为 156 点，黑钻会员 +32 即 188 点。每进入一个**新房间**扣 1 点，本次已经走过的房间不重复扣。疲劳为 0 时不能进入地下城；如果在地下城里耗尽，可以打完当前这次。
5. **死亡**：倒计时内可用复活币原地满状态复活（单人时被击数清零）；倒计时结束回城并**虚弱** 10 分钟（四维、HP、MP 下降，离线不计时，可花金币找 NPC 解除）。新角色送 5 枚复活币，之后每天免费领 1 枚。
6. **评价**：共 9 级 F/E/D/C/B/A/S/SS/SSS。
- 操作分：5 连以上的连击、凌空追击、合击。
- 技巧分：背击、破招、Over Kill。
- 被击数扣分。
- 2009 年玩家总结：操作满分 70、技巧满分 70，共 140 分；每被击 5 次扣分，扣分按房间数平均。

| 评级 | 分数 | 经验加成 |
|---|---|---|
| F | 0–34 | — |
| E | 35–44 | — |
| D | 45–54 | — |
| C | 55–64 | — |
| B | 65–74 | +5% |
| A | 75–84 | +10% |
| S | 85–94 | +15% |
| SS | 95–104 | +20% |
| SSS | 105 以上 | +30% |

7. **翻牌**：上排是免费牌，选 1 张；下排是**黄金卡牌**，要付金币才能翻。清图面积越大、击杀精英越多，奖励越好；组队时已死亡的队员也能翻牌。现版本黑钻会员多 1 张免费牌。经典期卡牌的具体张数【不确定，建议上排 2 张、下排 2 张】。

### 怪物原型（直接可做 AI）
- **哥布林**：近身棍击、动作慢；十夫长下令时冲上来火属性自爆。
- **投掷兵 / 青 / 赤哥布林**：远程直线投掷，青附冰冻、赤附火。冰霜哥布林投掷物可贯穿，还会开"寒冰甲"，贴身可能被冻。
- **十夫长**：用剑的指挥官，比哥布林快（原资料称暴击 3 倍伤害）。
- **猫妖**：跳扑抓咬；荧光猫妖给同伴回血，回血时站定并霸体，应优先击杀。
- **牛头兵 / 先锋**：霸体斧击，低头蓄力后长距离冲撞（附出血），被远程攻击时自动霸体。
- **牛头巨兽**：重拳砸地震人，伤害高但很慢。

## 7. 成长系统

### 7.1 等级与技能点
- **SP**：Lv2 获得 30 点，之后每级多 1 点（第 n 级获得 28+n 点）。累计：Lv15 为 511，Lv30 为 1276，Lv50 为 2646。另有任务奖励的 SP 书。Lv50 起升级还会获得 TP，用来强化已有技能。
- **经验来源**：击杀、通关奖励、评价加成、任务。等级与地下城差距过大时拿不到基础经验。

### 7.2 装备
- **稀有度（名称颜色）**：普通（白）→ 高级（蓝）→ 稀有（紫）→ 神器（粉）→ 传说（橙）→ 史诗（黄/金）→ 神话（彩色）。2008 年早期还有套装（绿）。
- **品级**：同一件装备的基础数值分 5 档（最下级到最上级），掉落时随机。
- **部位**：共 13 格。左列为头肩、上衣、下装、腰带、鞋；右列为武器、称号、手镯、项链、戒指、辅助装备、魔法石、耳环。早期先做前 10 格即可。另有时装和宠物。
- **防具类型**：布甲、皮甲、轻甲、重甲、板甲。每个职业精通一种：鬼剑士和圣职者重甲，神枪手皮甲，魔法师布甲，格斗家轻甲。穿精通的类型有加成，穿不精通的会降低攻速、施放速度和 MP 恢复。
- **其他**：武器有耐久度（例如太刀 30），需要找 NPC 修理；物品有重量，超出负重上限会受限。

### 7.3 属性
- 四维：力量→物攻，智力→魔攻，体力→HP/物防，精神→MP/魔防。
- 其他：物攻/魔攻/独立攻击（固伤技能用）、物理/魔法暴击（分开）、攻速/施放/移速、命中/回避、硬直（被打僵得短）/僵直度（打人僵得久）、四属性强化与抗性、HP/MP 每分钟恢复。

### 7.4 强化
- 在强化 NPC 处消耗金币和"无色小晶块"。加成：武器 → 无视防御的攻击力，防具 → 物理防御，首饰 → 魔法防御。

| +1～+3 | 100% |
| →+4 | 95% |
| →+5 | 90% |
| →+6 | 80% |
| →+7 | 75% |
| →+8 | 62.1% |
| →+9 | 53.7% |
| →+10 | 41.4% |
| →+11 | 33.9% |
| →+12 | 28% |
| →+13 | 20.7% |
| →+14 | 17.3% |
| →+15 | 13.6% |

- **失败惩罚**（官方新手引导，约 2012 年）：

| 情况 | 失败结果 |
|---|---|
| +3～+10 | 降 1 级 |
| 武器 +10→+11 | 降为 +7 |
| 武器 +11→+12 | 降为 +8 |

| 防具、首饰、特殊装备 +10→+11 | 破碎 |

  - 更早期流传的规则是：+4～+7 失败降 1 级，+8～+10 失败归零，+10 以上失败破碎。
- **保护券**：
  - 强化保护券：装备不会破碎，但强化等级归零。
  - 超级保护券：+11 以上失败时降为 +10。
  - 2021 年改版后，武器 +1～+12 失败不再掉级。
- 高等级强化成功会发全服公告，具体从几级开始【不确定】；强化后的武器带发光特效。
- **增幅**：在"异次元"装备上增加红字属性（四维之一）。失败规则：1～7 失败降 1 级，8～10 失败归零，11 以上失败破碎；有增幅保护券。
- **锻造**：只能锻造武器，提升独立攻击力；失败是否降级【不确定】。

### 7.5 金币、药剂与疲劳
- **金币**：来自怪物掉落、翻牌、出售装备；用于强化、修理、购买药剂、解除虚弱、翻金牌。
- **药剂**：分 HP 药和 MP 药，使用后有冷却。端游早期药剂的名称和数值【不确定】；手游版分三档，下级/中级/上级分别恢复 10%/20%/25%，可作参考。另有"精灵"类道具，可回复 1/3、1/2 或全部。
- **疲劳**：见第 4 节，每日 156 点，黑钻 188 点。

- **中期地下城（雷鸣废墟、格拉卡类）**：偏摇滚或电子融合，有失真吉他强力和弦、军鼓推进，小调英雄旋律，约 130–150 BPM【不确定】。

- **领主房**：部分地下城有专门的领主 BGM，镜像阿拉德资料的脚注中提到了领主 BGM。

### 8.2 标志性音效与【建议】做法
- **打击**：斩击为短促金属"嚓"+噪声，钝击为低频"咚"，配 hit stop；暴击再叠高频"锵"。

## 复刻优先级建议（最能定义 DNF 手感的 15 项）
1. **X 普攻连段，并可随时用技能取消**（强制机制），做出流畅连招的基础。

4. **霸体（红色描边）**，以及抓取技能可以抓住霸体目标的克制关系。

6. **打击停顿 + 屏幕震动 + 受击闪白**，决定打击感。
