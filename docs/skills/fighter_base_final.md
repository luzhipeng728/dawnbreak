# 格斗家（男）基础职业 · 逐技能对齐（class `fighter`，B3，无转职）

范围：`src/content/classes/fighter.js` 的普攻 4 段、跑攻肩撞、跳攻、15 个基础技能（13 个主动 + 疾风连击 / 钢筋铁骨 2 个被动），不含四个转职（B4~B7）。
这是第一版实装，没有“改前”：B0 只有普攻占位，技能全部是这次按官方写的。

比对依据：
- **A** = wiki.dfo.world 各技能页（`curl -A Mozilla`，指令从按键图标读，含冷却 / MP / 段数 / 范围 / 异常几率）
- **N** = namu 격투가(남)/공통스킬（2026-07，现版冷却 / 学习等级，见 `docs/SKILLS_OFFICIAL_fighter.md` 第 3 节）
- **V** = 技能页 YouTube 演示的缩略图 hq1~3（`i.ytimg.com/vi/<id>/hq{1,2,3}.jpg`，11 个技能有视频）和本作连拍 `test/shots/skills/fighter-base.jpg` 并排看；膝击 / 钢筋铁骨 / 瞬步 / 金刚碎的页面没有视频，只能按文字
- **T** = 本作测试：`node test/fighter.mjs base`（机制逐条）、`node test/skillaudit.mjs fighter --compare`（规格 `docs/skills/fighter.json`，13 个主动技能）

版本口径：冷却按 namu 现版（DFO 旧值不同时括号标出）；MP 按 DFO Lv1；等级按 common.md 第 7 节压缩（官方 20→16、30→18）；距离按官方 px × 1.05。

## 合计
- 18 行（普攻 / 跑攻 / 跳攻 + 15 个基础技能）：一致 14、近似 4（下段踢破霸体、分身上限、钢筋铁骨体力、抛沙飞行），做不到 0。
- 依据：文字 A 15 / 15、namu N 15 / 15、视频缩略图 V 11 个技能（膝击、钢筋铁骨、瞬步、金刚碎的页面没有视频）。
- 取消例外（官方）：念气波 = 气功师、抛沙 = 街霸、旋风腿 = 散打才能在普攻中取消（`S.noForce(p)`，引擎 `canCancelInto` 支持函数）；分身不能取消普攻。
- 引擎改动（player.js，两处）：`canCancelInto` 的 noForce 可以是函数；`downJumpCmd`：以 ↓ 结尾的 C 指令（蹲伏 ↓↓+C）匹配、能放时优先于后跳（↓+C），其他职业没有这种指令，不受影响。
- 图标：15 个 + 职业徽记 1 个，一张 4×4 表（`art/tools/fighter_base_art.py`，1 次生图）。特效全部复用 art/final/fx 运行时染色。
