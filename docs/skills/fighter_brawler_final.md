# 街霸（男格斗家 brawler，B6）逐技能对齐（第一版实装）

代码：`src/content/classes/fighter_brawler.js`（转职 ~ 20 级）、`fighter_brawler_p1.js`（一觉之后）；美术脚本 `art/tools/fighter_brawler_art.py`；测试 `test/brawler.mjs`、`test/fighter_brawler.mjs`。`docs/skills/fighter.json` 已补齐 20 个主动技能的规格；投掷物同时记录官方“再投间隔”和“装填冷却”，并用 DFO World Wiki / Nexon 资料复核。
`J.ready` 仍是 `false`（等 B1 出帧、主线程开放）；开发测试用 `?fighter=1`。

## 来源与方法
- 文字：docs/SKILLS_OFFICIAL_fighter.md 第 6 节（namu 2026-08 现版技能表 + 国服名）；wiki.dfo.world 的 29 个技能页（`curl -A Mozilla`，读“Description / Attributes / Notes / Skill Growth 第 1 行”：冷却、再投间隔、装填数、段数、异常、MP、指令图标）。
- 视频：技能页里的 YouTube 演示（19 个），取 `i.ytimg.com/vi/<id>/hq1~3.jpg` 三个瞬间拼图，和本作 `node test/brawler.mjs shots` 的连拍（`test/shots/brawler/`）并排比对“形状 / 颜色 / 节奏”。视频大多是 2015~2019 的旧版画面（伏虎霸王拳只有女版视频），现版改动以文字为准。
- 45 级锁链技能的国服现名：官方公告 / 攻略站写作「极恶飞锁」（kangehao 2025 技能进化专题；17173 2021 年资料还是旧的「血色风暴」）。
- 压缩规则（和其他职业一致）：等级按 common.md 第 7 节；MP 按本作的量级（同冷却档的其他职业技能）重定，不照搬 DFO 数值；百分比加成（后街战术 / 千手奥义 / 诡诈之道 / 逆道·皆允 / 挑衅伤害加深）按“官方 ×0.4~0.5”；刷图冷却照常乘 `p.cdMul`（×0.6 基准）。
- 伤害类型：全部 `type: 'mag'`；街霸在身时 `p.dmgType = 'mag'`（普攻和基础技能也按魔法结算，官方 2021 魔法化）。
