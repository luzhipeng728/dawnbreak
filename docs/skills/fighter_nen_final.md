## 数值口径（全转职统一的压缩规则，不逐个写）
- 学习等级：官方 Lv → 本作 `round(15 + (官方 − 15) × 15/85)`；转职 15、一觉 21、二觉 26/27、三觉 29/30。冷却写官方现版（namu），刷图冷却系数 ×0.6 由 recalcStats 统一乘。
- 伤害：官方技能攻击力是 % 值（几千到几十万），本作按冷却比例定“攻击力倍数”（冷却 5~7 秒 ≈ 3~4 倍、17~20 秒 ≈ 7.5~8、45~50 秒 ≈ 14、一 / 二 / 三觉 30+8/级、34+9/级、46+12/级，和魔法师同级技能同一条线）；段数 / 各段比例按官方。
- MP：本作 MP 尺度（官方旧 wiki 的 MP 是另一套数值），同级技能和其他职业一致。
- 颜色：念气 = 金黄 + 白色雷光（wiki：男气功光属性 + 感电、二觉外观是金色电光；视频：念气珠 / 金雷虎 / 归一都是金橙色）；**念气波 / 蓄念炮是蓝白色念气团**（视频 CDdyS8vhuAc）。

## 实现方式（给合并 / 后续块看）
- 钩子全走 B0 的接口：`FIGHTER_ACT_PICK`（龙虎啸换普攻）、`FIGHTER_HOOKS.onCast / onHit`（风雷能量、念气感知）、`CLASSES.fighter.passives`（进地下城自动施放、属性、能量回复）、`updateGroundFx` 包一层（念气珠碰撞 / 耗蓝），`ui.drawPanel` 懒包一层（能量条）。**没有改任何引擎 / 共享 js 文件**。
- 蓄念炮 / 幻影爆碎：官方是“改变基础技能”，本作做成本转职的主动技能（指令同原技能、冷却更长或学习等级更高 → 按千海天规则抢占同一指令）；B3 合并后 `SKILLS.f_nenshot / f_clone` 存在时，文件末尾给它们挂 `morph`（气功师学了就换成本技能），并给这两个技能加前置。
- 指令冲突（按官方）：风雷啸和念气环绕、禅语·形灭和月华万象同指令，长冷却的占指令，另一个只能放技能栏（技能说明里写了）。雷霆踏 →+Z 和 B3 膝击“按住→+Z”：按住 → 时膝击优先，点一下 → 再按 Z 是雷霆踏。
- 念兽：借用万年雪山雪虎（`spr/snTiger`）的逐帧图，蓝白转金色 + 罩一层金色（缓存），正常混合画半透明身体 + 叠加发光；分包没加载好时画程序剪影。以后有专门的念兽素材放 `fx/fn_beast_<kind>` 自动替换。
- 动画：新片段 `fnPalm / fnPalm2 / fnSeal / fnFocus / fnMed（打坐）/ fnRide（骑乘）/ fnStab（雷刃刺入）/ fnUp / fnAxe` 写在 `J.anims`（帧名 `fn_meditate / fn_ride / fn_stab / fn_up`，B1 出帧前兜底到格斗家通用帧 `f_palm1 / f_seal / f_focus / f_axe*`），矢量占位模型的骨骼片段也写了。
