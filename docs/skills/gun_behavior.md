# 神枪手（女）技能“怎么玩”对齐表（行为层，2026-09-29）

上一轮（`gun.json` + `skillaudit --compare`）只比数字：段数、冷却、霸体、范围。这一轮逐个技能比**玩法**：分几段、要不要再按 / 按住 / 连按 / 方向键、角色怎么移动、召唤物干什么、长什么样。
官方口径：国服 / 韩服现版。资料：`docs/SKILLS_OFFICIAL_gun.md`、`gun.json` 的 note，薄弱处（15 个觉醒 + 十来个招牌技能）补查了 NamuWiki 现版技能页（各职业页的觉醒小节，见 `gun.json` 的 src）。
一行一个技能：官方要点 | 本作现状（改之前）| 不一致 | 处理。“✔ 已改”的在 `test/gunner_jobs.mjs` 最后一组断言里有对应测试。被动技能只影响数值 / 形态，放在每节末尾一行。
