## 没对上的
- 官方摘要显示歼灭行动 / 超限压制 / 超负荷炮 / 爆刃突袭等标了“信息 N”，无法判断是获得还是消耗，仍按“获得”。
- 二觉被动的暴击率、三觉被动“硬编码”（攻击 / 技能攻击 18~38%，改动部分技能）本作没有，属技能表里没有的条目。
- 官方位移和判定框没有公开数据，沿用前几轮范围换算。
