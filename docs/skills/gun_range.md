# 神枪手（女）技能判定范围对齐表（范围层，2026-09-29）

前两轮对齐了“怎么玩”、段数、冷却，**判定的物理大小没有和官方比过**，用户反馈“好多技能的范围都太小了”。这一轮逐个技能比判定范围。
比例尺（详见 `docs/SKILLS_OFFICIAL_gun.md` 第 15 节“第 4 阶段”）：**官方 1 px ≈ 本作 1 个世界单位**（角色身高 本作 104～111 / 官方 100～110 px）；本作屏幕宽 960 = 官方现版（1067 宽）的 90%、60 版（800 宽）的 120%；可走纵深 196（人物在中间时上下各约 ±95）。
写法：数字都是世界单位。`前 a` = 向前的判定距离（从角色中心算），`±d` = 纵深半宽，`r` = 地面圆形半径（纵向按 0.45 压扁，所以 r 200 ≈ 纵深 ±90），`→` 左边是改前、右边是改后。
官方：**有数字的**（DFO Wiki 各技能页 Notes，2026-09 查）直接用；没有数字的按演示画面估算（占屏幕几成），估算宁大勿小；“—” = 没有判定（BUFF / 开关 / 被动）。
测量：`node test/gun_range.mjs gun:<转职>`（单个木桩逐点摆放，身前 70～900、身后 80 / 200、纵深 +30 / +60 / +90），结果在 `test/shots/audit/range-gun-*.json`。`gun.json` 里的 `far` / `deep` 是这张表的下限，`--min` 检查。
没改的：冷却（主线程统一 PvE ×0.6）、段数、伤害倍率、行为逻辑。PvP 另有 `PVP_JOB` 系数兜底（见文末）。
