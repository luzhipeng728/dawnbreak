## 说明
- skillshots 的两项提示是测试环境造成的，不是技能问题：炫纹要求“先直接命中过敌人”才能射（官方规则，脚本直接放就没有目标）；炫纹簇是 10s 后才自动爆炸，连拍只有几秒。两者的连拍里能看到炫纹环绕和星团。
- 共享文件没有改；替身草人的取消后摇通过在战法文件里包一层 mg_phase.act 实现。
- 改了数值的两处（战斗本能、炫纹增益）已复测决斗平衡：战斗法师 56%。

## 压缩规则（技能攻击力类加成）
本作的“数值”比官方低是有规则的，不是漏了：技能倍率表已经按压缩后的等级（官方 Lv100 = 本作 Lv30）给足，百分比类加成不再原样搬，其他职业统一按“官方 x0.4～0.5”：
- 元素师属性精通：官方 30+2n% -> 本作 10%+1%/级。
- 召唤师狂暴：官方约 45%+ -> 本作 5%+2%/级。
- 机械师：机器人强化 9%+2%/级。
- 战斗法师同理：战斗本能 (23+2n)% -> 10%+1%/级（10 级 20%，约 x0.45）；尼巫的战术 20%～40% -> 10%+1%/级；炫纹增益 20% -> 10%+0.5%/级；斗神意志官方 7%～85% -> 6%+1%/级。
- 第二轮中曾把战斗本能 / 炫纹增益抬到 15%，比其他职业高，已还原，保持一致；战斗法师决斗胜率因此维持 46%～56%（区间内）。
