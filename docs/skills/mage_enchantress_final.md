# 小魔女（enchantress）最终对齐（第二版，逐技能重对）

## 用了哪些来源
- wiki.dfo.world（curl 可读）：每个技能页的说明、属性表、备注（Rose Vines / Meticulous Stitching / Favoritism / Forbidden Curse / Madd 系 / Hot Affection / Destiny Puppet / Black Forest Brier / Bramble Prison / First Aid of Love / Marionette / Hex / Eternal Possession / Terrible Roar）。这是全球服，数值是上线版，和国服 / 韩服现版有出入。
- namu.wiki 技能页（curl 拿到完整表格）：韩服现版冷却、段数、范围、持续时间、操作说明、二觉 / 三觉细节。冷却和段数以它为准。
- 视频：wiki 上小魔女的技能页没有嵌视频（Video 全是 No Video）；namu 主页 / dfo wiki 主页只有职业宣传片和觉醒演示，用 i.ytimg.com 的 hq1~3 缩略图（J2hTlGa5rcA、kjCLYvlAHXU、TpSdyjbktyo、C8MB2F9my00、GXB_JiC2tos）对了：疯疯熊设计、一觉幕布颜色、咆哮吐息形状、谢幕爪痕、三觉红色火焰。其余技能没有官方画面，特效只能按文字说明对，记为“近似”。
- 国服页面 dnf.qq.com、灰机 wiki 都连不上 / 403，没有第三方国服来源。
