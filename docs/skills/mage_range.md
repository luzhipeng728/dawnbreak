# 魔法师技能范围对照（2026-09-29）

比例尺见 `docs/SKILLS_OFFICIAL_mage.md` 1.5 节：**官方 1px = 本作 1 个世界单位**（人物身高 104 ≈ 官方 105px；本作一屏 960 ≈ 现版 0.9 屏）。
官方没写数字的按那一节的档位估（宁大勿小）。只放大，不缩小；冷却、段数、伤害倍率、行为逻辑都没动。

写法：`前 N` = 人物前方判定前沿；`±N` = 纵深半宽；`rN` = 地面圆半径（纵向 ×0.45）；`[a,b]` = 相对人物的前后范围。
随机落点的多段技能（陨星幻灭、月蚀之影、使徒之舞、宇宙寂灭余波、杰克降临小陨石）放大散布时同步放大单发半径，保证单个目标吃到的段数和原来差不多。
