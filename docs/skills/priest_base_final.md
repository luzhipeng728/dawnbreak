# 圣职者（男）基础职业 · 逐技能对齐（class `priest`，P-core，无转职）

范围：`src/content/classes/priest.js` 的普攻 3 连、跑攻、跳攻、11 个基础技能（全部主动；现版没有基础被动，重甲精通是自动的防具精通）。4 个转职（圣骑士 / 蓝拳圣使 / 驱魔师 / 复仇者）归各自的块。
这是第一版实装，没有“改前”：外部智能体的 `priest.js`（13 个技能里 正义冲撞 / 疾风打 / 圣盾防御 / 圣光十字 / 圣光球 等不是现版基础技能，指令 / 冷却也是编的）整份重写。

比对依据：
- **A** = wiki.dfo.world 各技能页（`curl -A Mozilla`：指令从按键图标读，MP / 施放时间 / 冷却 / Lv1 各段百分比 / 攻击类型 / 范围；比 namu 旧一点）
- **N** = namu 프리스트(던전앤파이터)/남자/공통스킬（2026，现版冷却 / 学习等级公式 / 各转职差异 / 普攻取消）
- **V** = 技能页的 YouTube 演示 id（空斩打 thCt5aeqx9c、虎袭 mu2jpIegK7Q、直拳冲击 fhaWe_aheEM、勾拳追击 ynT_FnUmGXs、缓慢愈合 kANE3JkQVYk、净化 QrQDcvZWS_I、纯白之刃 GIFTBikeAs8、落凤锤 85Tn1ImbkdI；升天阵 / 恶魔之手 / 化魔的页面没有视频）
- **T** = 本作测试：`node test/priest.mjs base`（机制逐条）、`node test/skillaudit.mjs priest --compare`（规格 `docs/skills/priest.json`，11 个技能）、`node test/skillshots.mjs priest`（连拍 `test/shots/skills/priest-base.jpg`）

版本口径：冷却按 namu 现版；MP 按 DFO Lv1；学习等级按 namu 现版公式在 1 级时的角色等级，再按 common.md 第 7 节压缩（官方 20 → 本作 16）；距离按官方 px × 1.05。
伤害：官方百分比是 Lv.110 体系的数，本作按“同冷却的其他职业基础技能”定总量（冷却 2 秒 ≈ 1.8，3 秒 ≈ 2.1，5~6 秒 ≈ 2.9~3.3），**各段之间的比例照官方**。
人物现在是矢量占位模型（鬼剑士骨架 + 巨型十字架），美术块出帧后按 `SPR_ANIMS.priest` 自动换。

## 合计
- 14 行（普攻 / 跑攻 / 跳攻 + 11 个基础技能）：一致 10、近似 3（勾拳追击可直接放、缓慢愈合自动选目标、化魔按比例）、本作补 1（跳攻）。
- 依据：文字 A 11 / 11、namu N 11 / 11、视频 V 8 个技能。
- 取消例外（官方）：直拳冲击 = 蓝拳、升天阵 / 落凤锤 = 驱魔才能在普攻中取消（`S.noForce(p)`）；缓慢愈合 / 净化 / 化魔是 BUFF 类，不能取消普攻；转职限制：纯白之刃只有圣骑士（`only`），恶魔之手 / 化魔 / 升天阵圣骑士学不了（`excl`）。
- 已删除 / 不做：武器祝福、天使祝福（2018 圣骑士改版并入荣誉祝福）、强制-xx、旧 TP 强化。
- 图标：11 个 + 职业徽记 `p_crest`，一张 4×3 表（`art/tools/priest_base_art.py icons / iconcut`，1 次生图）；化魔那格被画成了宝箱，单独重出一张（`priest_base_art.py rapture`，1 次）。特效全部复用 art/final/fx 运行时染色。
