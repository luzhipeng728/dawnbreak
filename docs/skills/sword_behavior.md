# 鬼剑士技能“怎么玩”对照（行为级，2026-09-29）

上一轮 `docs/skills/sword.json` + `test/skillaudit.mjs --compare` 对的是数值（段数、冷却、霸体、范围）；这一轮对的是**玩法**：分几段、怎么输入（再按 / 按住 / 方向键 / 追加键）、往哪儿动、控制方式、标志画面。
来源：`sword.json` 的 `official` + `SKILLS_OFFICIAL_sword.md`；描述太薄的觉醒和招牌技能另查了 namu.wiki（2026-05/06 编辑版，含到 2026-04 的补丁记录）和 wiki.dfo.world。
每行格式：官方要点 | 本作现状 | 不一致 | 处理。“✅ 已改”是这一轮改的，“—”是本来就一致，“⚠ 未改”写了原因。
