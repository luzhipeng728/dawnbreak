# 鬼剑士技能判定尺寸对照（范围，2026-09-29）

起因：用户试玩说“45 的狂战士大崩（崩山裂地斩）范围太小，好多技能的范围都太小”。前两轮（`sword.json` 数值、`sword_behavior.md` 玩法）对的是段数、冷却、怎么玩，**没对过判定的物理尺寸**。这一轮逐技能把命中范围按官方尺寸放大，特效同比放大。比例尺和做法见 `docs/SKILLS_OFFICIAL_sword.md` 10.10。

- **换算**：官方 px × 1.05 = 本作单位（人物身高：官方约 105px，本作约 110）。纵深同比；本作地面圆的纵向半径 = 横向 × 0.45。
- **按屏幕想**：官方 800 宽画面的一半（400px）→ 本作 420，占本作屏宽 960 的 44%；官方 16:9 现版画面（≈1067 宽）的一半 → 本作 560，占 58%。现版演示视频都是 16:9，按“占屏宽比例 × 1120”估。
- **来源**：说明 = 技能说明 / namu.wiki / wiki.dfo.world 写明的 px（高置信）；演示 = 按演示画面覆盖比例估（中置信，按用户要求偏大取）。
- **判定口径**：`blast` 半径 r 打到离中心 r + 目标半宽（哥布林 11、人物 13）以内的目标；HB 框写成 `前沿0~前沿1 × 纵深半宽`。
- **实测覆盖**：scratch 工具在身前 −240~1000、纵深 0 / 40 / 80 三排钉住木桩（不会被打飞），逐帧放技能，记下被打到的木桩中心范围（负数 = 身后；“深 80+” = 纵深 80 那排也打到了）。抓取 / 追最强敌人 / 按最近几个敌人结算的技能，覆盖只反映它挑中的目标。
- **没动的**：冷却、段数、伤害倍率、行为逻辑。同一个目标吃到的段数用 `node test/skillaudit.mjs … --compare` 逐项核对（0 项未说明的不一致）；为了放大后段数不变：冰刃·波动剑冰柱 11 → 16 根、爆炎·波动剑爆炸 5 → 7 次（间距不变，只是排得更远）；流星落、死亡墓碑按散布面积同比放大落点半径。
- **决斗场**：范围放大后剑士整体胜率高了 8~12 个点，用 `PVP_JOB` 压回（见 10.10），没有缩小地下城的范围。
